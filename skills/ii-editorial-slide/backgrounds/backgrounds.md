# Манифест фонов

Формат блока:
```
## NN_filename.png
tags: тег1, тег2, тег3
zones: hero | full-bleed | rule | diagram-bg
mood: одно-два слова про настроение
note: 1 предложение что это и для какого смысла подходит
```

Я при сборке слайда читаю этот файл, ищу пересечение тегов с темой поста, беру 1–3 кандидата.

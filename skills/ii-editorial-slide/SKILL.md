# Skill: II Editorial Slide

Полноценный editorial-композит для постов канала И_И_ — не просто обложка, а слайд-разворот со всеми элементами поста на одном холсте.

## Триггеры

- editorial-слайд для канала И_И_
- собери разворот поста туннелирование / проходчики / рельса / [любой пост канала]
- сделай слайдумент для И_И_
- ii editorial
- разворот PP.MEDIA уровня референса

## Когда использовать

Когда нужен **плотный editorial-слайд** для поста канала. Не обложка (для обложки — `ii-channel-cover`), не глоссарий-справочник (для словаря — `glossary_slide`), а полный разворот темы:

- заголовок темы
- вводный текст из поста (4 абзаца)
- 5 шагов процесса с нумерацией
- уникальная для поста схема процесса (документ → узлы → результат)
- плашка с главным правилом
- декоративные элементы канала (прицел, blueprint-сетка, крестики)

## Source-fidelity (обязательно перед сборкой)

Слайд — разворот поста на одном холсте, не новый текст. Перед сборкой вычитать пост целиком и собирать из него (полная рамка — `Контент/_работа-над-ошибками-контента/00_рамка_10_ворот.md`):

- **Заголовок слайда = заголовок поста**, дословно.
- **4 абзаца intro берутся из поста**, не переписываются заново.
- **5 шагов покрывают реальную последовательность из поста**, не придуманную.
- **Диаграмма отражает логику поста**, не добавляет нового знания, которого в посте нет.
- **Главное правило — формулировка из поста.**
- Адресат — собственник/руководитель (G1); тема управленческая, не операционная мелочь. 24 анти-AI паттерна действуют на каждую надпись (G10), цифры — с источником из поста.

## Работа с библиотекой фонов

Наталья пополняет `backgrounds/` готовыми PNG (туннели, диспетчерские, бетон, чертежи и т.п.) и описывает каждый в `backgrounds.md` тегами и заметкой.

**Алгоритм при сборке нового слайда:**

1. Прочитать `backgrounds/backgrounds.md` — посмотреть весь манифест
2. Выделить из темы поста 3–5 ключевых смысловых тегов
3. Найти пересечение с тегами в манифесте → 1–3 кандидата
4. Если кандидатов несколько и разные по настроению — показать Наталье превью и спросить
5. Если один очевидный — взять и собрать
6. Если ни одного подходящего — сказать Наталье, что нужен новый фон с такими-то тегами

**В HTML фон подключается через путь `../backgrounds/имя_файла.png`** (рендер запускается с корня скилла, относительный путь работает).

**CSS-обработка фона под палитру (обязательно):**
```css
.hero img {
  filter: grayscale(35%) contrast(105%) brightness(95%);
}
.hero::after {
  /* мягкий переход в paper */
  background: linear-gradient(180deg, transparent 0%, var(--paper) 100%);
}
```

## Палитра канала (фиксированная)

| HEX | Назначение |
|---|---|
| `#EFEBE7` | Paper, фон слайда |
| `#D62219` | Акцент, номера секций, восклицательный знак, точка-маркер, красные стрелки |
| `#B8B3AD` | Линии, пунктир, blueprint-сетка |
| `#1A1714` | Текст, основные стрелки и контуры |

## Шрифты (Google Fonts через @font-face)

- **Unbounded** — заголовок поста (700/800/900), номера шагов 01–05, заголовки шагов UPPER, плашка правила
- **Inter Tight** — основной текст (Regular/Medium/SemiBold), описания, тело правила
- **JetBrains Mono** — служебные метки в правом верхнем (PP.MEDIA., номер выпуска, дата)

## Структура слайда (CSS Grid)

```
+-----------------------------------------------------+
|  HEADER ZONE  (red bar + title + meta right)        |
+--------+--------------------------------------------+
|        |  5 STEPS STRIP (01 02 03 04 05)           |
| INTRO  +--------------------------------------------+
|        |                                            |
| ----   |     MAIN DIAGRAM (unique per post)        |
| TARGET |     (SVG inline, hand-built)              |
+--------+--------------------------------------------+
|  RULE PLATE (red exclamation + label + body)        |
+-----------------------------------------------------+
```

Размер холста: **1600×1200 (4:3)** — рендер в 3200×2400 @2x. Формат выбран под Higgsfield, который по умолчанию генерит фоны 4:3 — так фоны нативно ложатся без обрезки и искажений. Перешли с 16:10 → 4:3 24.05.2026.

## Как создать новый пост

### Шаг 1. Скопировать template.html

```bash
cp template.html posts/NN_post_name.html
```

### Шаг 2. Заменить placeholder-блоки

В template.html помечены комментариями зоны для замены:
- `<!-- TITLE -->` — заголовок поста (Unbounded UPPER)
- `<!-- META -->` — номер выпуска и дата
- `<!-- INTRO -->` — 4 абзаца вводного текста
- `<!-- STEPS -->` — 5 нумерованных шагов
- `<!-- DIAGRAM -->` — основная схема (рисуется вручную в SVG под смысл поста)
- `<!-- RULE -->` — плашка главного правила

### Шаг 3. Рендер

```bash
python3 render.py posts/NN_post_name.html
# на выходе: posts/NN_post_name.png
```

## Запреты

- Не использовать Oswald (отменён правилами канала)
- Не использовать цвета вне палитры
- Не использовать эмодзи в текстах слайда
- Не использовать риторические зачины
- Не использовать «не X, а Y» паттерны и прочие правила Voice Profile
- Не выпускать без проверки по 24 анти-AI паттернам
- **Не использовать длинные тире `—` в текстах на слайдах** (зафиксировано 2026-05-24)
- **Не делать переносов после предлогов** («по / всем», «в / систему» — запрещено)
- **Не ставить подстрочник под заголовком** — заголовок дышит, объяснение даёт схема

# PP Survey Slides

Суб-скилл pp-slidument. Создаёт блок слайдов по результатам количественных опросов (анкетирование / квостер).

> **Визуальный стиль, палитра, типографика, паттерны раскладки** — наследуются из `pp-slidument`.
> Этот скилл НЕ дублирует визуальные правила — он определяет контентную структуру слайдов опросов.

---

## 0. КРИТИЧЕСКИЕ ПРАВИЛА

1. **Это БЛОК, не полная презентация.** По умолчанию = 6 слайдов (1 вводный + 5 кластеров). Если кластеров больше/меньше или нужно другое количество — скажут явно.
2. **Входные данные = результаты количественного опроса** с кластеризацией. Формат входных данных может быть разным (см. секцию «Форматы входных данных»).
3. **Все правила pp-slidument действуют**: action titles, плотность 1000+ символов, визуализация на каждом слайде, слева направо, минимум 10pt.
4. **Каждый кластер = ПОРТРЕТ** с данными. Не абстрактное описание, а конкретные цифры: доля %, демография, факторы с баллами, поведение.
5. **Графики и диаграммы ОБЯЗАТЕЛЬНЫ.** На вводном слайде — как минимум: диаграмма распределения кластеров (pie/donut) или матрица. На слайдах кластеров — столбчатые диаграммы факторов выбора, круговые диаграммы демографии. Текст-only = ошибка.

## 0.1. ФОРМАТЫ ВХОДНЫХ ДАННЫХ

Данные опроса могут прийти в разных форматах. Задача скилла — извлечь нужные метрики из любого формата.

### Формат А — Excel / CSV (идеальный)

Готовая таблица с агрегированными данными по кластерам. Можно сразу строить слайды.

**Что искать в файле:**
- Лист/таблица с разбивкой по кластерам (столбцы = кластеры, строки = метрики)
- Или: строки = респонденты, столбец «Кластер» = номер кластера → нужно самостоятельно агрегировать

### Формат Б — Ссылка на дашборд (интерактивный)

Пользователь даёт URL дашборда (DataLens, Power BI, Metabase, Google Data Studio, кастомный).

**Алгоритм работы:**
1. Открыть дашборд через браузер (MCP Chrome)
2. Сделать скриншот общей картины
3. Последовательно фильтровать по каждому кластеру и снимать данные:
   - Переключить фильтр «Кластер» → К1
   - Скриншот + считать данные с графиков/таблиц
   - Повторить для К2, К3, К4, К5
4. Собрать все данные в единую структуру → строить слайды
5. **Если что-то не читается с экрана** — спросить пользователя

**Что искать на дашборде:**
- Фильтр по кластерам (выпадающий список, кнопки, табы)
- Графики факторов выбора (bar chart / radar)
- Демографические распределения (pie / donut / stacked bar)
- Таблицы с метриками по кластерам
- Показатели: доля кластера, средний балл, %, N

### Формат В — Доступ к серверу / БД дашборда

Пользователь даёт доступ к серверу, где хранятся данные дашборда (API, SQL, Jupyter).

**Алгоритм работы:**
1. Подключиться к серверу (SSH, API endpoint, Jupyter notebook)
2. Найти таблицы/датафреймы с результатами кластеризации
3. Выполнить запросы для извлечения агрегатов по кластерам:
   - Распределение респондентов по кластерам (COUNT, %)
   - Средние баллы факторов выбора по кластерам
   - Демография (пол, возраст, доход) по кластерам
   - Поведение (частота, сценарии) по кластерам
4. Собрать данные → строить слайды

**Типичные SQL-запросы:**
```sql
-- Доли кластеров
SELECT cluster_id, COUNT(*) as n,
       ROUND(COUNT(*)*100.0 / SUM(COUNT(*)) OVER(), 1) as pct
FROM survey_results GROUP BY cluster_id;

-- Факторы выбора по кластерам
SELECT cluster_id, factor_name, ROUND(AVG(score), 2) as avg_score
FROM survey_results JOIN factors ON ...
GROUP BY cluster_id, factor_name ORDER BY cluster_id, avg_score DESC;

-- Демография по кластерам
SELECT cluster_id, gender,
       ROUND(COUNT(*)*100.0 / SUM(COUNT(*)) OVER(PARTITION BY cluster_id), 1) as pct
FROM survey_results GROUP BY cluster_id, gender;
```

### Формат Г — Скриншоты / PDF отчёт

Пользователь присылает скриншоты дашборда или PDF-отчёт аналитика.

**Алгоритм работы:**
1. Прочитать каждый скриншот / страницу PDF
2. Извлечь числовые данные из графиков и таблиц
3. Если данные нечитаемы — попросить пользователя уточнить конкретные цифры
4. Собрать данные → строить слайды

### Формат Д — Текстовое описание

Пользователь описывает результаты словами или копирует текст из отчёта.

**Алгоритм работы:**
1. Извлечь все числовые данные из текста
2. Структурировать по кластерам
3. **Если данных недостаточно** — запросить у пользователя недостающие метрики (см. чек-лист ниже)
4. Строить слайды

### Минимальный чек-лист данных (для любого формата)

Без этих данных слайд НЕ МОЖЕТ быть построен — нужно запросить у пользователя:

| Данные | Зачем | Критичность |
|--------|-------|-------------|
| Количество кластеров | Определяет кол-во слайдов | 🔴 Обязательно |
| Доля каждого кластера (%) | Ключевая метрика в заголовке и donut | 🔴 Обязательно |
| Названия / описания кластеров | Action title + описание | 🔴 Обязательно |
| N выборки | Вводный слайд, источник | 🔴 Обязательно |
| Факторы выбора + баллы | Столбчатая диаграмма — основа слайда | 🟡 Очень важно |
| Демография (пол, возраст) | Портрет кластера | 🟡 Очень важно |
| География | Вводный слайд | 🟢 Желательно |
| Поведение (частота, сценарии) | Портрет кластера | 🟢 Желательно |
| Мотивы и барьеры | Детализация портрета | 🟢 Желательно |
| Экономика (чек, эффективность) | Бизнес-вывод | 🟢 Желательно |

**Правило:** если 🔴 данных нет — СТОП, запроси. Если 🟡 нет — предупреди, что слайд будет слабее. Если 🟢 нет — делай без них.

## 1. СЛАЙД 1 — ВВОДНЫЙ (факторная матрица + обзор кластеров)

### Суть
Показывает ВСЮ аналитическую картину на одном слайде: полную факторную матрицу, scatter-plot дисперсии, описания всех кластеров и общий портрет аудитории.

### Обязательные элементы

| Блок | Содержание | Расположение |
|------|-----------|-------------|
| Action title | Главный вывод кластеризации с данными | Верх, на всю ширину |
| Факторная матрица (heatmap) | Все факторы × все кластеры, цветовая шкала зелёный→красный | Левый верх (~45% ширины) |
| Scatter-plot дисперсии | Среднее значение × Дисперсия для всех факторов, пунктирные линии медиан | Левый низ (~45% ширины) |
| Таблица кластеров | N, Название, Описание (2-3 предл.), Доля %, Эк. эффективность | Правый верх (~55% ширины) |
| Общий портрет аудитории | Текстовый блок 4-5 предложений о типичном пациенте/клиенте | Правый низ |
| Шкала эк. эффективности | «Экономическая эффективность: высокая, средняя, низкая» (цветная) | Подвал |

**Ключевые правила паттерна:**
- Heatmap в таблице: зелёный (≥4,5) → жёлтый (3,5-4,5) → оранжевый (2,5-3,5) → красный (<2,5)

- Таблица кластеров: строка на каждый кластер = короткое название + описание 2-3 предложениями + % + экономическая эффективность (если есть)
- Общий портрет: 4-5 предложений — ядро возраста, триггер обращения, каналы поиска информации

## 2. СЛАЙДЫ 2–6 — КЛАСТЕРЫ (по 1 слайду на каждый)

### Суть
Максимально плотный портрет одного кластера: ВСЕ данные из дашборда/таблицы, отфильтрованные на этот кластер, на одном слайде. Левая колонка = синтез и выводы, правая = сырые данные (графики из дашборда, таблицы).

### Обязательные элементы на каждом слайде кластера

| Блок | Что содержит | Расположение |
|------|-------------|-------------|
| **Action title** | Название кластера + ядро возраста + ключевое поведение | Верх, на всю ширину |
| **Полоска доли** | ДОЛЯ % ∣ Клиенты X% (зелён.) ∣ НеКлиенты Y% | Сразу под заголовком |
| **Отличительные детали** | Доход, возраст, занятость, эк. эффективность — с иконками | Левый верх |
| **Таблица «Проблемы / Момент / Время»** | 3 колонки: почему обращаются, когда, удобное время | Левый центр |
| **Пирамида бренда** | Знаю → Посещаю → Считаю лучшим (3 колонки с %) | Левый низ |
| **Каналы привлечения** | Список с % (рекомендации, интернет, отзывы) | Левый низ |
| **Портрет сегмента** | 1,5 абзаца текстом: кто эти люди, как себя ведут, что важно. Человеческий русский, без канцелярита. | Левый низ (под каналами) |
| **Таблица факторов** | Все факторы: бары для кластера + значение «Всего» (dual-bar) | Правый верх |
| **Мини-графики из дашборда** | Все секции 3.x–5.x, отфильтрованные на кластер, dual-bar формат | Правый центр и низ |

**Ключевые правила паттерна:**
- **Левая колонка (~45%)** = синтезированные данные, выводы, стратегии. Включает: отличительные детали с иконками, таблицу «Проблемы/Момент/Время», пирамиду бренда, каналы привлечения
- **Правая колонка (~55%)** = сырые данные из дашборда. Включает: таблицу всех факторов (бары кластера + значение «Всего»), мини-графики по КАЖДОЙ секции дашборда (3.1, 3.2, 3.3, 3.5, 3.7, 3.10 и т.д.)
- **Таблица факторов**: горизонтальные бары для текущего кластера + число «Всего» через вертикальную черту → читатель видит отклонение от среднего
- **Мини-графики**: воспроизводятся из дашборда в уменьшенном виде (8-9pt шрифт). НЕ пересказываются текстом — именно графики
- **Пирамида бренда**: три колонки «Знаю | Посещаю | Считаю лучшим» с топ-3 брендами и процентами
- **Если данных из дашборда нет** (пользователь дал только таблицу) — правая колонка содержит только факторы + демографические pie charts
- **Портрет сегмента**: 1,5 абзаца текстом под каналами привлечения (отделён коралловой линией). Пишется человеческим русским языком: кто эти люди, что им важно, как себя ведут, что мотивирует/не мотивирует. Без канцелярита, без абстракций — конкретика и характер сегмента
- **Dual-bar формат графиков**: каждый мини-график показывает ДВА значения: бледная полоска = «Всего» (среднее по всей выборке), яркая полоска поверх = значение конкретно по этому кластеру. Читатель сразу видит отклонение от нормы

## 4. АЛГОРИТМ РАБОТЫ

```
1. ОПРЕДЕЛИ ФОРМАТ ВХОДНЫХ ДАННЫХ (см. секцию 0.1):
   А) Excel/CSV → читай файл напрямую
   Б) Ссылка на дашборд → открой в браузере, фильтруй по кластерам, снимай данные
   В) Доступ к серверу/БД → подключись, выполни запросы агрегации
   Г) Скриншоты/PDF → прочитай визуально, извлеки цифры
   Д) Текстовое описание → структурируй, запроси недостающее

2. ИЗВЛЕКИ ДАННЫЕ — проверь по чек-листу минимальных данных (секция 0.1):
   - 🔴 Обязательно: кол-во кластеров, доли %, названия, N выборки
   - 🟡 Очень важно: факторы выбора + баллы, демография
   - 🟢 Желательно: география, поведение, мотивы, экономика
   - Если 🔴 не хватает → СТОП, запроси у пользователя

3. Определи:
   - Сколько кластеров (по умолчанию = 5)
   - Есть ли нарезка на клиенты/неклиенты (если да — возможно больше слайдов)
   - Какие метрики есть (демо, факторы, поведение, экономика)

4. Собери вводный слайд:
   - Action title = главный вывод кластеризации
   - Методология + обзор всех кластеров
   - ОБЯЗАТЕЛЬНО: диаграмма или матрица-карта

5. Для каждого кластера:
   - Выбери паттерн (Портрет / Профиль / Строка таблицы)
   - Action title = вывод о кластере (не «Кластер 3», а «Кластер 3: молодые мамы ценят...)
   - Заполни все обязательные блоки с конкретными цифрами
   - ОБЯЗАТЕЛЬНО: минимум 1 диаграмма (факторы выбора = столбчатая)

6. Итого: 1 вводный + N кластерных = обычно 6 слайдов

7. Проверь по чек-листу pp-slidument
```

### Выбор паттерна кластерного слайда

| Ситуация | Паттерн | Почему |
|----------|---------|--------|
| Есть дашборд с секциями 3.x (поведение, бренды, каналы) | **Максимальная плотность (СвДж)** | ВСЕ данные на одном слайде: синтез + сырые графики |
| Только факторы + демография, нет дашборда | Портрет-карточка (Восточка) | Достаточная плотность при ограниченных данных |
| Нужно уместить 2–3 кластера на слайд | Строка таблицы (Румяный каравай) | Компактность, единый формат сравнения |
| Кластеров > 5, нужна экономия места | Строка таблицы | По 2–3 кластера на слайд |

### Выбор паттерна обзорного слайда

| Ситуация | Паттерн | Почему |
|----------|---------|--------|
| Есть факторная матрица по кластерам + scatter | **Факторная матрица (СвДж)** | Полная картина: данные + кластеры + портрет |
| Нет факторной матрицы, нужна методология | Четыре квадранта (Румяный каравай) | Методология + pie chart |
| Быстрое сравнение без глубокой аналитики | Сводная таблица (OLSO) | Компактно, по делу |

## 7. ТЕХНИКА: ГЕНЕРАЦИЯ ГРАФИКОВ ЧЕРЕЗ MATPLOTLIB

Скриншоты дашбордов из браузера невозможно сохранить на диск (CSP, sandbox macOS). Решение: **генерировать графики через matplotlib** как PNG и вставлять в PPTX через `add_picture()`.

### Архитектура (2 скрипта)

1. **`gen_mini_charts.py`** — генерирует все PNG-графики в папку `dashboard_screenshots/`
2. **`survey_slides_svdj.py`** — собирает PPTX, вставляет PNG через `slide.shapes.add_picture()`

### Типы графиков

| Тип | Функция | Где используется |
|-----|---------|-----------------|
| Факторы выбора | `gen_factors_chart()` | Правая колонка, верх (большой, ~3.6" высота) |
| Горизонтальные бары dual-bar | `gen_horizontal_bar()` | Мини-графики 2×2 (why_visit, motive, channels, moment) |
| Пирамида бренда | `gen_brand_pyramid()` | Мини-график (Знаю/Посещаю/Лучший) |
| Scatter дисперсии | `gen_scatter_overview()` | Обзорный слайд (среднее × std dev) |

### Dual-bar формат (КРИТИЧНО)

Каждый bar chart должен показывать ДВА значения:
- **Бледная полоска** (`#BDD7F6`) = значение «Всего» (по всей выборке)
- **Яркая полоска** (`#2E7CDC`) поверх = значение по конкретному кластеру
- Сортировка по значению кластера (descending)
- Шрифт 7-8pt, подписи справа от баров

### Размеры для встраивания в 16:9

| Элемент | Размер в PPTX | figsize matplotlib |
|---------|---------------|-------------------|
| Факторы (большой) | 6.2" × 3.6" | (8, 5) |
| Мини-график | 3.05" × 1.5" | (5, 3) |
| Scatter обзорный | 5.5" × 3.2" | (7, 4.5) |

### Палитра PP для matplotlib

```python
PP_BLUE = '#2E7CDC'       # яркая полоска (кластер)
PP_BLUE_PALE = '#BDD7F6'  # бледная полоска (всего)

PP_GRAY = '#6B7280'        # подписи

```

# Skill: II Channel Cover (PP.MEDIA)

Генерация обложек постов канала «И_И_» — отдельного бренда PP.MEDIA внутри Paper Planes.

## Триггеры

- собери обложку для поста И_И_
- сделай обложку канала И_И_
- ii cover
- pp media cover
- обложка PP.MEDIA
- обновить обложку поста канала И_И_
- собери визуал для нового поста канала

## Когда использовать

Когда нужна обложка для:
- поста Telegram-канала И_И_ (формат 1280×720)
- кросс-промо в Instagram канала PP.MEDIA (1080×1350 портрет или 1080×1080 квадрат)
- одиночной карточки-открытки с одной мыслью канала

Не использовать для:
- основного канала Paper Planes (PP_посты) — там свой стиль
- канала Б&П — там фирстиль Балахнина v3 (Oswald + штамп + sheet head)
- слайдов клиентских презентаций — там consulting-slides-creator

## Source-fidelity и ворота (обязательно)

Обложка — поверхность, где дрифт виден сразу. Текст на ней берётся из поста, не сочиняется заново (полная рамка — `Контент/_работа-над-ошибками-контента/00_рамка_10_ворот.md`):

- **Заголовок обложки = заголовок поста**, дословно. Не переформулировать «покрасивее».
- **Слоганы (пары «и-и») берутся из тела поста** или из его главной мысли, не генерируются с нуля. Если пост про выбор/конфликт — слоганы отражают этот конфликт, а не шаблонную «и-и».
- **Адресат — собственник/руководитель** (G1): заголовок говорит на языке управленческой темы поста, не операционной мелочи.
- **24 анти-AI паттерна действуют на каждую надпись** (G10): в заголовке и слоганах нет «не X, а Y», power words, одушевления, англицизмов без нужды. Если в надписи есть цифра — источник должен быть в посте.

## Чем отличается от фирстиля Балахнина

Палитра та же (paper / ink / M-RED / muted), композиция другая.

| Элемент | Балахнин v3 | И_И_ канал |
|---|---|---|
| Display-шрифт | Oswald (sans, плотный) | Playfair Display Black (serif, контрастный) |
| Композиция | технический лист с штампом, sheet head, signoff | свободная композиция с blueprint-подложкой |
| Линии | плотные, размерные с засечками | тонкие, пунктирные окружности, лёгкая сетка |
| Логотип | подпись Балахнина SVG в углу | лейблы PP.MEDIA. + PAPER PLANES + paperplane-иконка |
| Акценты | квадратные плашки, чёткие | пунктирные диагонали, тонкая красная стрелка |
| Шум | film grain через turbulence | лёгкое бумажное зерно |
| Кириллица | да | да (Playfair Display поддерживает) |

## Визуальный язык — фиксированные элементы

1. **Фон** — M-PAPER #F8F5ED, тёплый бумажный
2. **Blueprint-подложка** — несколько лёгких пунктирных окружностей (stroke 0.5–1px, opacity 0.15) + редкие крестики-перекрестия
3. **Главный заголовок** — Playfair Display Black, очень крупно, чёрный M-INK, с подчёркиваниями `_` после букв (например, `И_И_.`)
4. **Красная точка-квадрат** — справа от заголовка, M-RED, 0.5–0.7em высоты заголовка
5. **Подзаголовки** (3 пары «и-и») — Inter Tight Regular, чёрный M-INK, акцентное слово (например, «ИИ») красным M-RED
6. **Красная диагональная стрелка** — длинная, тонкая (1.5–2px), идёт снизу-слева вверх-направо
7. **Шапка** — `PP.MEDIA.` в верхнем левом углу (Inter Tight 16pt, чёрный, с точкой); `PAPER PLANES` в верхнем правом + иконка бумажного самолётика M-RED
8. **Красный блок-акцент** — квадратная плашка M-RED в одном из углов (10–15% площади максимум)
9. **Опциональная диаграмма** — простая блок-схема в правом нижнем углу: квадраты с подписями (СИСТЕМА / ЛЮДИ / ДАННЫЕ / ИИ) и тонкие соединительные линии. ИИ красным.
10. **Опциональная фотовставка** — фрагмент архитектурного фото (бруталистская лестница, монохром) в левом нижнем углу. Опционально, не обязательно.

## Палитра (нормы — те же, что у Балахнина 60/25/10/5)

| Код | Имя | HEX |
|---|---|---|
| M-RED | Red | `#E84A38` |
| M-INK | Ink | `#1A1714` |
| M-PAPER | Paper | `#F8F5ED` |
| M-MUTED | Muted | `#8A857A` |

Запрет: синий из бренда Балахнина (`#1C3A6E`) не используется в И_И_. Только paper / ink / red / muted.

## Типографика — три семейства, три роли

| Код | Семейство | Роль |
|---|---|---|
| T-01 · DISPLAY | **Playfair Display Black** | Главный заголовок «И_И_», крупные акценты |
| T-02 · SANS | **Inter Tight** (Regular / Medium) | Подзаголовки, слоганы, текст диаграмм |
| T-03 · MONO | **JetBrains Mono** (500) | Метки `PP.MEDIA.`, `PAPER PLANES`, технические подписи |

Oswald и Unbounded из стека Балахнина в И_И_ **не используются**.

## Запреты

- Никакого Oswald в заголовках
- Никаких теней, градиентов, blur
- Никакого синего
- Никаких эмодзи
- Красного не более 10% площади
- Не использовать заглавные литеры везде (только в шапке и в редких акцентах)

## CLI

```bash
python3 build.py \
  --title "И_И_." \
  --slogans "и ИИ, и человек" "и скорость, и качество" "и технологии, и риск" \
  --format tg \
  --diagram on \
  --photo /path/to/photo.png \
  --output post_cover.png
```

### Параметры

- `--title` — главный заголовок (по умолчанию `«И_И_.»`). Допустимы латиница и кириллица. Подчёркивания и точки сохраняются.
- `--slogans` — список 1–4 коротких слоганов «и X, и Y». Акцентное слово через инлайн-маркер `<r>ИИ</r>` для красного.
- `--format` — `tg` (1280×720), `ig_portrait` (1080×1350), `ig_square` (1080×1080)
- `--diagram` — `on` / `off` (по умолчанию `on` для tg, `off` для квадрата)
- `--photo` — путь к монохромной архитектурной фотографии для левого нижнего фрагмента (опционально)
- `--output` — путь куда сохранить PNG (по умолчанию `cover.png` в текущей папке)
- `--no-arrow` — выключить красную диагональную стрелку
- `--seed` — фиксированный seed для воспроизводимости расположения окружностей

# Выбор носителя

| Запрос | Основной носитель | Исполнитель | Обязательная проверка |
|---|---|---|---|
| Плотная аналитическая презентация | HTML 16:9 + PPTX | `pp-slidument` | контактный лист, критики, целевой просмотрщик |
| Редактируемый PowerPoint | Native PPTX | `presentations` + правила builder | редактируемость объектов, шрифты, PowerPoint |
| Быстрый показ без редактирования | Raster PPTX | HTML + PNG в PPTX | совпадение HTML и PPTX |
| Интерактивная витрина | PP Pages | HTML 16:9 + shell | публичный маршрут, навигация, адаптивность |
| Методичка или печатный материал | A4 PDF | `pp-print-a4` | печатный рендер всех страниц |
| Одностраничный визуальный материал | HTML one-pager | Presentation Kit + профильный скилл | реальный браузер на целевой ширине |
| Реестр или насыщенная таблица | HTML/PP Pages | Presentation Kit + табличный инструмент | фильтры, ширина, мобильный вид |

Сначала выбрать управленческую задачу и плотность материала. Затем выбирать носитель и профильный скилл.

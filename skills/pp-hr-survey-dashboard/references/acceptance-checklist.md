# Чек-лист приёмки HR-дашборда

## Данные

- [ ] Подсчитаны все заполненные анкеты сотрудников.
- [ ] Подсчитаны все заполненные анкеты кандидатов.
- [ ] Исключены пустые и технические строки.
- [ ] Нет потерянных респондентов после объединения таблиц.
- [ ] Нет ответов без респондента, вопроса или фактора.
- [ ] Все вопросы источника сопоставлены визуализации, фильтру или зафиксированному исключению.
- [ ] Все факторы представлены в расчётах.
- [ ] Все роли представлены в таблице.
- [ ] Показан индикатор охвата данных.

## Расчёты

- [ ] Для одиночного выбора рассчитаны доли от текущей выборки.
- [ ] Для множественного выбора рассчитаны доли респондентов.
- [ ] Размеры групп не подменяют доли.
- [ ] Для шкал рассчитаны средние баллы.
- [ ] Стандартное отклонение рассчитано в единицах шкалы.
- [ ] Сравниваемые шкалы приведены к общей основе.
- [ ] Разрывы рассчитаны в пунктах шкалы.
- [ ] Пустые значения исключены только из соответствующего показателя.

## Фильтры

- [ ] Нажатие на столбец меняет остальные визуализации.
- [ ] Нажатие на сегмент меняет остальные визуализации.
- [ ] Нажатие на точку меняет остальные визуализации.
- [ ] Нажатие на строку таблицы меняет остальные визуализации.
- [ ] Одновременные фильтры работают согласованно.
- [ ] Проценты пересчитываются с новым знаменателем.
- [ ] Пустая выборка имеет понятное состояние.
- [ ] Сброс очищает все фильтры и масштаб.

## Точечные диаграммы

- [ ] Под осью X есть двухсторонний ползунок.
- [ ] Слева от оси Y есть двухсторонний ползунок.
- [ ] Ползунки меняют границы осей и растягивают выбранный диапазон.
- [ ] У бегунков нет белой двойной обводки.
- [ ] Точки и подписи имеют цвет `#181D27`.
- [ ] Названия факторов видны без наведения.
- [ ] После масштабирования подписи размещаются заново.
- [ ] Стрелки и соединительные линии отсутствуют.
- [ ] Проверка пересечений подписей возвращает ноль.
- [ ] Полноэкранный режим работает.

## Таблица по ролям

- [ ] В строках находятся факторы, в столбцах — роли.
- [ ] В ячейках показаны средние баллы.
- [ ] Для каждой роли указан размер группы.
- [ ] Цветовой диапазон рассчитан отдельно по каждой роли.
- [ ] Высокие значения зелёные, низкие красные.
- [ ] Цвета приглушённые.
- [ ] Заголовок и первый столбец закреплены.
- [ ] Все строки доступны без внутренней вертикальной прокрутки.
- [ ] Полноэкранный режим показывает всю таблицу.

## Интерфейс и выпуск

- [ ] Три плотных точечных графика занимают полную ширину.
- [ ] Полноэкранный режим закрывается кнопкой и клавишей Escape.
- [ ] Дашборд пригоден для снимка экрана.
- [ ] На рабочей ширине нет обрезанного текста.
- [ ] В консоли браузера нет ошибок.
- [ ] Проверены исходное состояние, фильтр, масштаб, полный экран и сброс.
- [ ] Публичная версия совпадает с принятой локальной версией.

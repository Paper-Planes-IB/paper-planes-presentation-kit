# Шаблоны и структура КП

## Обязательный скелет (core)

| # | Секция | Назначение | Рекомендуемый slide type |
|---|--------|-----------|--------------------------|
| 1 | Титульный слайд | Название проекта, клиент, дата | `title_dark` |
| 2 | Контекст (SCQA) | Ситуация, Осложнение, Вопрос, Ответ | `scqa` |
| 3 | Цели и задачи | Что должно измениться | `numbered_list` / `goals_rows` |
| 4 | Подход / методология | Логика решения (НЕ самопрезентация) | `chevron_process` / `flow_blocks` |
| 5 | Этапы — overview | Общая карта проекта | `roadmap_swimlane` / `stage_gate` |
| 6-8 | Этап N — детали | Конкретика по каждому этапу | `table_sidebar` / `process_detail` |
| 9 | Результаты и импакт | Что получит заказчик | `from_to` / `exec_summary` |
| 10 | Сроки, команда, стоимость | Экономика проекта | `table_sidebar` / `segment_matrix` |
| 11 | Следующие шаги | Условия старта | `next_steps` |

**Правила адаптации:**
- 1-2 этапа: секции 6-8 сжимаются
- Проект без IT-компоненты: убрать IT-блоки
- Стратегический проект: добавить сценарии (Base / Opt / Cons)

## Опциональные секции

Добавляются ТОЛЬКО если оправданы задачей:
- Альтернативные сценарии (Base / Opt / Cons) -> `comparison`
- Границы ответственности (что не делаем) -> `do_dont`
- Риски и допущения -> `segment_matrix`
- Примеры артефактов -> `mechanism_card`
- Roadmap внедрения после проекта -> `roadmap_swimlane`
- `divider` ЗАПРЕЩЕН (обучение Балахнина 21.03.2026)

## Секция «О нас» (особый случай)

- Заголовок: «Подход Paper Planes к решению задач в отрасли [Отрасль]»
- 3-4 конкретных решения из отрасли клиента
- «Кто воспользовался и внедрил» — типы клиентов
- НЕ общая самопрезентация, а релевантный опыт

## Запрещённые секции

- Абстрактная самопрезентация без привязки к отрасли
- Исторические справки без связи с задачей
- Перечни инструментов без ответа «зачем»
- Методологию как самоценность
- Универсальные маркетинговые блоки «про всё»

## Особенности по типам проектов

### Стратегические проекты
- Больше логики, меньше инструментов
- Связка с решениями собственников
- Сценарии (Base / Opt / Cons) почти обязательны
- Фреймворк «3 стратегических решения»:
  1. Роль на рынке
  2. Модель дохода
  3. Рычаги роста

### Аналитика / данные / BI
- Максимум конкретики, минимум концептов
- Четкие поля, метрики, источники данных
- Примеры дашбордов / таблиц как артефакты

### HR / EVP / EJM
- Акцент на управляемость (не на «культуру»)
- Метрики: текучесть, time-to-hire, eNPS

### Оргструктура / оргдизайн
- Модель 8 функций (расширенный Адизес)
- ЦФО, RUN-CHANGE-DISRUPT-FIX, RASCI
- Типичные ошибки клиентов как SCQA-контекст

### Продажи / маркетинг
- Экономическая логика, формула прибыли как каркас
- Связка с выручкой / маржой / конверсией

### Абонентское сопровождение
- Подписная модель: 4 уровня
- Фиксированная часть + Success Fee
- Аргумент: сравнение с наймом

## Gold Standard (из 56 реальных КП)

Полный анализ: `gold-standard-patterns.md`

### Реальная последовательность слайдов
1. Титульный (темный) -> КП на [что] для [Клиент]
2. О нас (опционально) -> Подход PP к задачам в отрасли
3. Цель и задачи (1-2 слайда)
4. Этапы — overview
5. Этап N — детали (1-2 слайда на этап)
6. Сроки и стоимость
7. Приложение (опционально)
8. Финальный -> «Агентство, которое знает, что дальше»

### Паттерн «Цель и задачи» (ключевой слайд)
Один слайд: Цель + Текущее положение + Задачи + Этапы + Эффекты

### Паттерн «Аналитическая матрица»
Строки: направления анализа (10-15), Столбцы: методы (5-9), Ячейки: действия и результаты

### Количественные обязательства
ВСЕГДА включать: N интервью, M конкурентов, длительность, охват

### Методологии PP
Формула прибыли, 6 рычагов роста, 8 функций компании, RUN-CHANGE-DISRUPT-FIX, ЦФО, RFM/DSL/SPL, TCO, 5 сил Портера, RASCI, PAM/TAM/SAM/SOM, EST-модель, Пирамида бренда.
Подробности: `pp-methodology-notion.md`

## 4. ОСОБЕННОСТИ ПО ТИПАМ ПРОЕКТОВ

### Стратегические проекты
- Больше логики, меньше инструментов
- Чёткая связка с решениями собственников
- Акцент на варианты выбора, а не единственную «рекомендацию»
- Сценарии (Base / Opt / Cons) — почти обязательны
- Использовать фреймворк «3 стратегических решения»:
  1. Роль на рынке (операционное превосходство / экосистема / стандарт)
  2. Модель дохода (откуда деньги, средний чек, частота, маржинальность)
  3. Рычаги роста (география / продукты / каналы / сегменты)

### Аналитика / данные / BI
- Максимум конкретики
- Чёткие поля, метрики, источники данных
- Минимум концептов, максимум схем
- Примеры дашбордов / таблиц как артефакты

### HR / EVP / EJM
- Акцент на управляемость (а не на «культуру»)
- Избегать «мягкого» языка
- Чёткая связка с бизнес-результатами
- Метрики: текучесть, time-to-hire, eNPS — конкретно

### Оргструктура / оргдизайн
- Использовать модель 8 функций (расширенный Адизес)
- ЦФО: зелёные → синие → жёлтые → красные
- RUN-CHANGE-DISRUPT-FIX для диагностики задач
- RASCI как артефакт, SLA между подразделениями
- Типичные ошибки клиентов как SCQA-контекст:
  - Маркетинг = центр прибыли (нет)
  - Котловой метод издержек
  - Внедрение до описания процессов

### Продажи / маркетинг
- Экономическая логика
- Связка с выручкой / маржой / конверсией
- Минимум креатива, максимум причинно-следственных связей
- Формула прибыли как каркас

### Абонентское сопровождение (подписная модель)
- Альтернативный формат КП: не проект, а подписка
- 4 уровня: еженедельный трекинг / ежемесячные тактические /
  квартальные стратегические / методологическая поддержка
- Ценообразование: фиксированная часть + Success Fee по результату
- Ключевой аргумент: сравнение с наймом (стоимость, экспертиза, старт, риски)
- Фокус на передаче компетенций команде клиента

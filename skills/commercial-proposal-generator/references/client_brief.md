# Опросник клиентского брифа

## Минимальный вход (без этого КП не пишется)

- [ ] Описанная задача (не тема, а конкретная управленческая проблема)
- [ ] Горизонт проекта (сроки)
- [ ] Тип решения (стратегия / аналитика / оргмодель / продажи)
- [ ] Ожидаемый уровень конкретики

## Расширенный бриф (дозапрашивать, если не дано)

### Блок 1 — Контекст
- Кто заказчик (роль, не компания)
- В чем управленческая боль сейчас
- Почему проект запускается именно сейчас
- Что уже пробовали / делали

### Блок 2 — Цель
- Какой управленческий результат нужен
- Что должно измениться в принятии решений
- По каким признакам проект считается успешным

### Блок 3 — Ограничения
- Сроки
- Глубина (диагностика / внедрение / сопровождение)
- IT-ограничения
- Границы ответственности

### Блок 4 — Формат
- Какие артефакты ожидаются
- Для кого они будут использоваться
- Кто принимает финальное решение

## Классификация типа проекта

По ответам определить категорию:
- **Стратегия** — роль на рынке, модель дохода, рычаги роста
- **Аналитика / BI** — данные, метрики, дашборды
- **HR / EVP / EJM** — текучесть, eNPS, оргкультура
- **Оргструктура** — функции, ЦФО, процессы
- **Продажи / маркетинг** — выручка, конверсия, каналы
- **Абонентское сопровождение** — подписка, трекинг, success fee

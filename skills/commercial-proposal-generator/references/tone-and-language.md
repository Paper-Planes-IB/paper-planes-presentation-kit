## 1. СТОП-ЛИСТ: запрещённые слова и обороты

### Категория: маркетинговые гиперболы
| Запрещено | Почему | Замена |
|-----------|--------|--------|
| уникальный | пустое обещание | убрать или конкретизировать |
| революционный | гипербола | конкретное описание изменения |
| прорывной | гипербола | конкретный результат |
| инновационный | затёрто | описать что именно нового |
| передовой | оценочно | конкретика |

### Категория: маркетинговые клише
| Запрещено | Замена |
|-----------|--------|
| поможем выйти на новый уровень | конкретный результат: «увеличить конверсию на X%» |
| комплексное решение всех проблем | «решение задачи X через Y» |
| комплексный подход | убрать или описать конкретные шаги |
| синергия | конкретный эффект взаимодействия |
| экосистема решений | перечень конкретных артефактов |

### Категория: абстракции без содержания
| Запрещено | Почему | Замена |
|-----------|--------|--------|
| проработка | без уточнения = пусто | «анализ X», «формализация Y» |
| повышение эффективности | нет метрики | «сокращение цикла с X до Y дней» |
| улучшение взаимодействия | абстракция | «формализация процесса передачи данных между отделами» |
| оптимизация процессов | абстракция | конкретный процесс + конкретная метрика |
| трансформация | абстракция | «переход от X к Y» |

### Категория: канцелярит
| Запрещено | Замена |
|-----------|--------|
| что позволит | → точка. Новое предложение с результатом |
| что способствует | → конкретное следствие |
| в рамках проекта | убрать (контекст и так понятен) |
| на основании вышеизложенного | убрать |
| с целью | → «чтобы» или «для» |
| осуществить | → «сделать», «провести», «выполнить» |

### Категория: позиционирование
| Запрещено | Почему |
|-----------|--------|
| мы — эксперты в | продажа экспертизы вместо результата |
| наш богатый опыт | самопрезентация |
| мы гарантируем | невозможно гарантировать в консалтинге |
| мы используем авторскую методологию | самолюбование |

## 2. ШАБЛОНЫ УДАЧНЫХ ФОРМУЛИРОВОК

### Вводный слайд / первое предложение
```
✅ «Проект направлен на формализацию управляемой модели [X] и запуск
   регулярного управленческого цикла принятия решений.»

✅ «Цель проекта — [конкретный результат], позволяющий руководству
   принимать решения на основе данных, а не экспертных предположений.»

❌ «Мы предлагаем комплексный подход к решению задач компании.»
❌ «Наша команда поможет вам выйти на новый уровень.»
```

### Описание этапа
```
✅ «На этапе 1 формируется аналитическая база проекта: проводится анализ
   данных, интервью с ключевыми ролями и первичная декомпозиция
   проблемного поля.»

✅ «Этап 2 — построение модели [X]: на основе данных этапа 1 формируется
   [конкретный артефакт], включающий [перечень элементов].»

❌ «На данном этапе осуществляется комплексная проработка всех аспектов.»
❌ «Проводится глубокий анализ с использованием передовых методик.»
```

### Результаты
```
✅ «По итогам проекта у компании появляется единая логика управления [Z],
   закреплённая в данных, регламентах и управленческих артефактах.»

✅ «Карта рыночных сегментов с оценкой потенциала и приоритизацией
   по критериям доходности и доступности.»

❌ «Проведение анализа рынка.» (результат ≠ процесс)
❌ «Повышение общей эффективности бизнеса.» (абстракция)
```

### Стоимость
```
✅ «Стоимость проекта определяется объёмом аналитических работ,
   количеством вовлечённых ролей и глубиной проработки
   управленческих решений.»

✅ «Стоимость включает: [N] дней полевой работы, [M] интервью,
   [K] итераций модели, финальную презентацию результатов.»

❌ «Стоимость проекта — X рублей.» (без обоснования)
```

### Методология
```
✅ «Мы начинаем с декомпозиции формулы прибыли и выявления
   ключевых рычагов роста…»

✅ «Логика проекта: от диагностики текущего состояния → к целевой модели
   → к плану перехода.»

❌ «Мы используем авторскую методологию 6 рычагов роста…»
❌ «Применяем лучшие мировые практики стратегического консалтинга.»
```

## 3. ПАТТЕРНЫ ПО ТИПАМ ПРОЕКТОВ

### Стратегия
- Акцент на выбор: «три сценария развития: базовый, оптимистичный, консервативный»
- Связка с решением собственника: «позволяет принять обоснованное решение о…»
- Варианты, не рекомендации: «каждый сценарий включает оценку рисков и потенциала»

### Аналитика / BI
- Конкретные поля данных: «сегментация по SKU, каналу, региону, периоду»
- Метрики: «LTV, CAC, retention rate, средний чек»
- Артефакты: «интерактивный дашборд в [инструмент], обновляемый [частота]»

### HR / EVP / EJM
- Управленческий язык: «модель управления текучестью» (не «забота о сотрудниках»)
- Метрики: «eNPS, time-to-hire, стоимость замены»
- Связка с P&L: «снижение текучести на X% = экономия Y млн руб/год»

### Продажи / маркетинг
- Формула прибыли: «выручка = трафик × конверсия × средний чек × частота»
- Рычаги: «ключевой рычаг — конверсия из лида в сделку (текущая X%, целевая Y%)»
- Unit-экономика: «CAC, LTV, payback period, маржинальность по каналам»

## 4. АНТИПАТТЕРНЫ (частые ошибки)

### Ошибка: подмена результата процессом
```
❌ Результат: «Проведение серии интервью с ключевыми сотрудниками»
✅ Результат: «Карта болевых точек с приоритизацией по влиянию на бизнес»
```

### Ошибка: одинаковые описания этапов
```
❌ Этап 1: «Анализ текущего состояния и выявление проблем»
   Этап 2: «Анализ данных и выявление возможностей»
   Этап 3: «Разработка рекомендаций и план действий»

✅ Этап 1: «Диагностика: декомпозиция воронки продаж по каналам»
   Этап 2: «Моделирование: построение unit-экономики по сегментам»
   Этап 3: «Дорожная карта: план действий с ответственными и сроками»
```

### Ошибка: обучающий тон
```
❌ «Важно понимать, что сегментация клиентов — это ключевой инструмент…»
✅ «Сегментация клиентской базы по [критериям] — основа для…»
```

### Ошибка: защита методологии
```
❌ «Наша методология доказала свою эффективность в 50+ проектах…»
✅ (не писать этого вообще — методология раскрывается через логику решения)
```

### Ошибка: расширение рамки без согласования
```
❌ Бриф: аналитика продаж → КП включает HR-аудит и IT-трансформацию
✅ Бриф: аналитика продаж → КП про аналитику продаж, с пометкой
   «смежные области для отдельного проекта: [список]»
```

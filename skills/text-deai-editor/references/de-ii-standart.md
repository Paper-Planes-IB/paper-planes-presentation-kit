# Де-ИИ стандарт

Применяется ВСЕГДА — к заметкам, отчётам, ответам в чате, постам в Mattermost, статьям, КП, главам книг. Текст должен быть точным, проверяемым, нейтральным, человеческим.

## 24 запрещённых паттерна

### Смысловые

1. **Раздувание значимости без фактов.** Не «переломный момент», «уникальный», «революционный», «беспрецедентный». Если событие важное — назови, чем именно (число, имя, дата, последствие).
2. **Перечисление медиа/брендов вместо проверяемого факта.** Не «писали Forbes, Vedomosti, RBC» — выбери один источник + конкретное утверждение с датой.
3. **Абстракции «символизирует / отражает / демонстрирует» без конкретики.** Заменить глаголом действия с измеримым результатом.
4. **Размытые атрибуции.** Не «эксперты считают», «многие полагают», «известно, что». Имя или источник — или сужай формулировку.
5. **Шаблонные «трудности».** Не «несмотря на трудности... продолжает процветать». Конкретные препятствия + конкретный результат.
6. **Рекламный язык и пафос.** Не «лидирующее решение», «передовая методология», «инновационный подход».

### Лексика

7. **ИИ-маркеры.** Удалять: «кроме того», «свидетельство», «ландшафт», «демонстрируя», «безусловно», «в эпоху», «в условиях», «в рамках», «в контексте».
8. **Канцелярит-глаголы.** Не «служит», «включает в себя», «может похвастаться», «представляет собой» — писать «это», «есть», «имеет», «включает».
9. **Отрицательные параллелизмы.** Не «не только X, но и Y». Просто «X и Y» или «X. Y».
10. **Принудительное «правило трёх».** Если по делу два — пиши два. Если четыре — четыре.
11. **Цикл синонимов.** Один объект — один термин на весь документ. Не «компания → организация → бизнес → структура → игрок».
12. **Ложные диапазоны.** Не «от X до Y» — перечислить напрямую: «X, Y, Z».

### Пунктуация и форматирование

13. **Перебор с длинным тире.** Длинное тире `—` только для составных имён, прямой речи, перечислений. В остальных случаях — запятая или точка.
14. **Перебор с **жирным**.** Жирный — только для ключевого тезиса абзаца, не для каждой второй строки.
15. **Списки-заголовки в строке.** Не «Преимущества: скорость, цена, качество». Либо абзац, либо bullet-список с раскрытием.
16. **Title Case в русских заголовках.** В русском — только первое слово с заглавной + собственные имена. «Стратегия 2026», не «Стратегия 2026 Года».
17. **Эмодзи без явной просьбы.** Никаких 🚀, ✨, 💡 в текстах для людей. Исключение — если Илья прямо попросил.

### Артефакты чатбота

18. **Концовки.** Не «Надеюсь, это поможет!», «Дайте знать, если нужны уточнения», «Готов помочь дальше».
19. **Дисклеймеры.** Не «поскольку деталей мало...», «без полного контекста сложно...». Если деталей мало — задай 1-2 вопроса.
20. **Подлизывание.** Не «Отличный вопрос!», «Прекрасное замечание!», «Интересная мысль!».

### Канцелярит и оговорки

21. **Канцелярские обороты.** Не «в целях», «в силу того что», «в связи с необходимостью», «осуществляется», «производится». Пиши «чтобы», «потому что», «делает».
22. **Избыточные оговорки.** Не «может потенциально возможно». Один модификатор уверенности — максимум.
23. **Общие концовки.** Не «будущее выглядит светлым», «возможности велики», «потенциал огромен».
24. **Стрелочные связки →.** В прозе писать «затем», «после этого», «следовательно». Стрелки — только в схемах, диаграммах, маршрутах процессов.

## Англицизмы

По умолчанию — переводить. Английский остаётся, только если общепринятый отраслевой термин и русский эквивалент звучит нелепо.

| Англицизм | Перевод |
|---|---|
| roadmap | дорожная карта |
| must-have | обязательно |
| nice-to-have | желательно |
| MVP | пилот / минимально работающая версия |
| A/B-тест | сравнительный тест |
| no-show | неявка |
| TCO | полная стоимость владения |
| M&A | сделка слияния-поглощения |
| pipeline | конвейер / поток |
| backlog | очередь / задел |
| KPI | показатель / метрика (если контекст требует — оставлять) |
| OKR | цели и ключевые результаты (OKR — допустимо как термин) |
| follow-up | следующий шаг / дальнейшая работа |
| insight | вывод / находка |
| stakeholder | заинтересованный участник |
| onboarding | ввод в курс / первичный запуск |
| handover | передача / переход |
| benchmark | эталон / контрольный замер |
| best practice | проверенная практика |
| case study | разбор кейса |

Правило ввода термина: первое упоминание — `«дорожная карта (roadmap)»`, дальше — только русский. Исключение — `SKU`, `LTV`, `RFM`, `BPM`, `CJM` — индустриальные сокращения, оставляем английские.

## Принципы

- **Короткие предложения.** До 20 слов в среднем. Длинные — только если связь требует.
- **Активный залог.** «Команда запустила» вместо «было запущено».
- **Повтор термина допустим**, если повышает ясность. Не подменяй ради красоты.
- **Если утверждение нельзя проверить — сужай.** «По данным X на дату Y...» вместо «известно, что...».
- **Direct speech клиента — дословно с пометкой источника.** «[Сергей Громов, Аконит, 18/04/2026] „...“».

## Формат при прямом вызове `/text-deai-editor`

При прямом вызове скилла дополнительно выдавать:
1. Исправленный текст.
2. Список изменений (паттерн → было → стало).
3. Вопросы автору, если без него не сужается.

# text-deai-editor

## Назначение

Убирать ИИ-звучание и приводить текст к де-ИИ стандарту Ильи.

## Когда использовать

- `убери ИИ`
- `почисти текст`
- `deai`
- редактура клиентского текста

## Источники

- `references/de-ii-standart.md` — полный де-ИИ-стандарт Ильи: 24 запрещённых паттерна, таблица англицизмов, принципы (короткие предложения, активный залог, сужение непроверяемого). Прогонять текст по нему.
- `references/format-vyvoda.md` — формат вывода (BLUF, decision packet, запрещённые форматы). Для ответов/брифов, не для постов.
- Оригиналы у Ильи: `Vault/ПКМ/де-ии-стандарт.md`, `Vault/ПКМ/формат-вывода.md` (диск Ильи) — сверять при обновлении стандарта.

## Workflow

1. Прочитать `references/de-ii-standart.md`.
2. Пройти текст по 24 паттернам + таблице англицизмов (штампы, канцелярит, ИИ-маркеры, тире, англицизмы).
3. Привести формулировки к коротким активным предложениям.
4. Сохранить смысл и фактуру, а не только сделать «звучание человечнее».
5. Для клиентских deliverables не добавлять яркость ценой точности.
6. Выдать: исправленный текст → список изменений (паттерн → было → стало) → вопросы автору, если без него формулировка не сужается.

## ПРИНЦИП ВИЗУАЛЬНОГО РАЗНООБРАЗИЯ

**Слайдумент должен выглядеть как профессиональная работа Big 3, а не как 15 одинаковых таблиц.**

### Правило 1: Один тип НЕ более 2 раз подряд

- ❌ Слайд 3: table → Слайд 4: table → Слайд 5: table
- ✅ Слайд 3: table → Слайд 4: chart → Слайд 5: table

**Единственное исключение:** `scqa` может идти 2 раза подряд, если контент принципиально разный.

### Правило 2: Перед каждым `table` — проверь ВСЕ альтернативы

Прежде чем выбрать `table`, пройди этот чеклист:
1. ☐ Данные — процесс? → `chevron_process`, `flow_blocks`
2. ☐ Данные — сравнение 2 вариантов? → `comparison`, `from_to`
3. ☐ Данные — список рекомендаций/действий? → `numbered_list`
4. ☐ Данные — числа с динамикой? → `chart`, `waterfall`
5. ☐ Данные — иерархия/структура? → `treemap`, `sankey`

**Только если НИ ОДИН альтернативный тип не подходит — используй `table`.**

### Правило 3: Целевое распределение для 10-15 слайдов

| Категория | Целевая доля | Мин. количество |
|-----------|-------------|-----------------|
| Таблицы (`table`, `multi_table`) | ≤ 30% | — |
| Графики (`chart`, `chart_table`, `waterfall`) | ≥ 15% | 1-2 слайда |
| Диаграммы (`sankey`, `treemap`, `matrix`, `funnel`) | ≥ 10% | 1 слайд |
| Процессы (`chevron_process`, `flow_blocks`, `mermaid`) | ≥ 10% | 1 слайд |
| Текстовые (`scqa`, `numbered_list`, `comparison`) | 20-40% | 2-4 слайда |
| Метрики (`data`, `from_to`) | 5-15% | 0-2 слайда |

### Правило 4: Принцип "таблица — последний довод"

**Таблица уместна ТОЛЬКО когда:**
- Данные реально табличные (строки × столбцы с числами)
- Нужно сравнить 3+ объектов по 4+ параметрам
- Данные содержат Harvey Balls, RAG-статусы
- Нужна RASCI-матрица или аналог

**Таблица НЕ уместна когда:**
- Перечисляете рекомендации → `numbered_list`
- Описываете процесс → `chevron_process`
- Показываете до/после → `from_to`
- У вас 2-3 варианта → `comparison`

### Пример сбалансированного 12-слайдового слайдумента

| № | Содержание | Тип | Обоснование |
|---|-----------|-----|-------------|
| 1 | Контекст и проблема | `scqa` | Классическая структура аргументации |
| 2 | Ключевая метрика | `data` | Акцент на главном числе |
| 3 | Динамика показателей | `chart` (column) | Визуализация тренда |
| 4 | Декомпозиция изменения | `waterfall` | Вклад каждого фактора |
| 5 | Конкурентное сравнение | `table` с RAG | Много параметров × много конкурентов |
| 6 | Позиционирование | `matrix` | 2×2 наглядно |
| 7 | Путь клиента | `flow_blocks` | Визуальная цепочка этапов |
| 8 | Воронка конверсии | `funnel` | Потери на каждом этапе |
| 9 | SWOT-анализ | `swot` | Стратегическая структура |
| 10 | Финансовые показатели | `multi_table` | Сравнение 3 продуктов |
| 11 | План трансформации | `chevron_process` | Этапы внедрения |
| 12 | Рекомендации | `numbered_list` | Пронумерованные действия |

**Результат:** 12 слайдов, 10 разных типов, 0 повторений подряд, таблицы = 1 из 12 (8%).

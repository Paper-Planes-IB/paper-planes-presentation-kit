## Предотвращение ошибок (из реальных проектов)

| Ошибка | Причина | Решение | Правило |
|--------|---------|---------|---------|
| Пустое пространство при большом контенте | Статические кегли 5.5-6pt | Adaptive sizing (квадратичная формула calc_size/calc_adaptive_size) | Генератор решает автоматически, но sidebar items нужно заполнять на 80%+ |
| Roadmap с 3 колонками вместо 4 | Хардкод timeline_sections | Передавать `timeline_sections` в JSON-конфиг | Всегда задавать `timeline_sections` явно если периодов ≠ 3 |
| Некорпоративные цвета (синий, зелёный фон) | Копирование из других источников | Строго PP палитра: coral, gray_dark, gray_med, gray_light | RASCI — единственное исключение (цветные роли) |
| Монотонность (10 table подряд) | Лень при выборе типа | Алгоритм 6 шагов + правило "не более 2 подряд" | Каждый слайд проверять по алгоритму |
| Sidebar пустой на 60% | Мало items в sidebar | Добавить контекст, источники, детали, разбить на подпункты | Sidebar items должны заполнять 80%+ высоты |
| JSON parse error из-за кавычек | Русский текст с «ёлочками» внутри строк | Экранировать: `\"` или использовать одинарные кавычки в тексте | Проверять JSON через `json.loads()` перед генерацией |
| Контент обрезан ради макета | 5 аргументов → 3 в scqa | Выбрать тип с большей вместимостью (table, numbered_list) | Никогда не обрезать контент — менять тип слайда |
| Перекос competitive emphasis | 30 упоминаний одного конкурента, 2 другого | Grep-аудит частотности, целевая коррекция | После генерации проверять баланс упоминаний конкурентов |

## Чек-лист качества

- [ ] Заголовок — action title (вывод, не тема)
- [ ] Подзаголовки — тоже action titles
- [ ] НЕТ подписей S/C/A на слайде
- [ ] Минимум 2 источника (триангуляция)
- [ ] Контент развёрнутый, с цифрами
- [ ] Harvey Balls вместо %% где уместно
- [ ] RAG статусы для визуального сравнения
- [ ] Нет теней и украшательств
- [ ] Тип слайда выбран по Алгоритму (6 шагов)
- [ ] Визуальное разнообразие проверено (не более 2 одинаковых подряд)
- [ ] Все тексты на русском (проверка целостности)
- [ ] Числа из текста → график, не таблица
- [ ] Тип слайда соответствует каталогу (35 типов через единый генератор)
- [ ] Sidebar заполнен на 80%+ высоты (если используется)
- [ ] JSON валиден (проверить `python3 -c "import json; json.load(open('config.json'))"`)
- [ ] Баланс конкурентных упоминаний проверен (для стратегических слайдументов)
- [ ] Тон мягкий, консалтинговый (нет "требует", "критически", "провал", "полностью отсутствует")
- [ ] Данные качественных исследований не экстраполированы ("респонденты отмечают", не "X% клиентов")
- [ ] Методология объяснена до показа результатов (сначала модель, потом выводы)
- [ ] Группировка обоснована по MECE или явно указан принцип деления
- [ ] Нет ИИ-лексики и антипаттернов (24 паттерна проверены: "ландшафт", "свидетельство", "демонстрируя", абстракции, раздувание)
- [ ] Нет стратегических клише без конкретики ("ядро", "хвост", "локомотив", "драйвер", "витрина")
- [ ] Нет стрелочных цепочек (→), конструкций "не только X, но и Y" / "X, а не Y"
- [ ] Англицизмы переведены или расшифрованы при первом упоминании (SKU, MVP, roadmap и т.д.)
- [ ] Нет канцелярита ("В целях", "В рамках", "В силу"), избыточных оговорок, общих концовок

## Лог дополнений: Рокада Мед TTM (06.02.2026)

Паттерны, отработанные на 17-слайдовом слайдументе по стратегической сессии Рокада Мед (TTM — Time to Market для дистрибутора стоматологического оборудования). Применён Enhanced Reverse Prompting для извлечения.

### 1. Адаптивный расчёт размера шрифта (`calc_adaptive_size`)

**Проблема**: статические кегли (5.5-6pt) оставляют пустоту при малом контенте и переполняют при большом. Увеличение контента парадоксально увеличивает whitespace (шрифт уменьшается, но число строк не компенсирует).

**Решение**: квадратичная формула `s = √(target_h × avail_w / (chars × 0.50 × 1.18))`, заполняющая 87% высоты ячейки. Кегль зажат в [5pt, 9pt], округлён до 0.25pt. Line spacing = кегль × 1.18, округлён до 0.5pt.

**Функции в src/core/typography.py**: `calc_adaptive_size()`, `fill_cell_text_adaptive()`, `fill_cell_bullets_adaptive()`

### 2. Shape-based таблицы (`make_rect`)

**Проблема**: native PPTX tables (`.add_table()`) не дают контроля над per-cell backgrounds, overlaid accent bars, precise margins.

**Решение**: таблицы из `MSO_SHAPE.RECTANGLE` shapes. Каждая "ячейка" — отдельный прямоугольник с text frame. Даёт пиксельный контроль.

**Функция**: `make_rect(slide, left, top, width, height, fill_color, border_color, border_width)`

### 3. XML vertical anchor (`set_vertical_anchor`)

**Проблема**: `MSO_ANCHOR.TOP/MIDDLE` не всегда работает для shapes.

**Решение**: прямая манипуляция `<a:bodyPr anchor="t|ctr|b">` через XML.

### 4. Split-run bullets (▪ coral + dark text)

**Проблема**: `"• " + text` — одноцветный, не брендированный.

**Решение**: два run в одном paragraph: `run_bullet.font.color = CORAL` + `run_text.font.color = GRAY_DARK`. Функция `fill_cell_bullets_adaptive()`.

### 5. Расширенная палитра

Добавлены в `COLORS`:
- `coral_light` (#FFEBEA) — highlight backgrounds, TO BE cells
- `coral_mid` (#FFC8C5) — secondary coral tint
- `cell_alt_bg` (#FAFAFD) — subtle zebra striping (белый → фиолетово-белый)

### 6. Layout: Content + Sidebar (63/37%)

**Паттерн**: основной контент (63%) + sidebar (37%) с gap 0.05". Sidebar содержит structured items (label в CORAL bold + value в GRAY_DARK). Items разделены GRAY_LIGHT divider lines (0.003").

Пример:
```python
sidebar_gap = Inches(0.05)
left_w = available_w * 0.63 - sidebar_gap / 2
right_w = available_w * 0.37 - sidebar_gap / 2
right_x = MARGIN + left_w + sidebar_gap
```

### 7. Left accent bars

Каждая секция получает CORAL полоску 0.025" по левому краю: `make_rect(slide, x, y, Inches(0.025), h, COLORS['coral'])`

### 8. Удаление слайдов (`remove_slides_after`)

Для замены слайдов в существующей презентации: `remove_slides_after(prs, keep_count)` удаляет все слайды после указанной позиции.

### 9. Итерационные уроки

| Итерация | Ошибка | Исправление |
|----------|--------|-------------|
| v1 | Sparse content, whitespace | Удвоить контент, добавить transcript quotes |
| v2 | Non-PP colors leaked (blue, green) | Strict palette enforcement. RASCI — единственное исключение |
| v3 | Static font → more content = more whitespace | Adaptive sizing (квадратичная формула) |
| v4 | Fonts resolved but sidebar empty | Adaptive sizing для sidebar с target_fill=0.90, max_pt=7.5 |

## САМООБУЧЕНИЕ НА ОШИБКАХ

### Перед генерацией слайдумента
1. Прочитай файл `corrections.md` (если существует) в директории скилла
2. Проверь, нет ли в нём правил, релевантных текущему контенту
3. Применяй все накопленные правила

### После получения правок от пользователя
1. Запиши правку в `corrections.md` (раздел "История корректировок")
2. Если правка повторяется 2+ раза — сформулируй ПРАВИЛО в разделе "Общие правила"
3. Если правило противоречит SKILL.md — обнови SKILL.md

### При каждой генерации
Добавь в `corrections.md` раздел "Лог генераций":
```
### [YYYY-MM-DD] Генерация: [output.pptx]
- Типы слайдов: scqa, chart, waterfall, table, numbered_list, ...
- Распределение: 20% table, 30% chart, 50% other
- Проверка разнообразия: ✅ OK / ❌ нарушено правило X
```

### Формат записи правки
```
### [YYYY-MM-DD] Проект: [название]
- **Ошибка**: [что было неправильно]
- **Исправление**: [что сделано]
- **Правило**: [обобщённое правило, если применимо]
```

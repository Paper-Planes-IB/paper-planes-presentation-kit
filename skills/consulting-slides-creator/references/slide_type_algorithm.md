## АЛГОРИТМ ВЫБОРА ТИПА СЛАЙДА

**ОБЯЗАТЕЛЬНО** выполнять перед созданием каждого слайда. Неверный выбор типа = плохой слайд.

### Шаг 1: Определи характер данных

| Характер данных | Приоритетные типы |
|----------------|-------------------|
| Числа, метрики, динамика | `chart`, `data`, `waterfall` |
| Сравнение вариантов/конкурентов | `comparison`, `table`, `from_to` |
| Процесс, этапы, шаги | `chevron_process`, `flow_blocks`, `mermaid` |
| Стратегия, аргументация | `scqa`, `numbered_list`, `pyramid` |
| Структура, иерархия, декомпозиция | `treemap`, `sankey`, `issue_tree` |
| Цитата, голос клиента, интервью | `quote` |
| Матрица ответственности (RASCI) | `rasci` |
| Контент + ключевые метрики рядом | `table_sidebar` |
| Стратегический roadmap | `roadmap_swimlane` |
| Этапы проекта / gate review | `stage_gate` |
| Правила / риски (do vs don't) | `do_dont` |
| Кампании/объекты × периоды (светофор) | `segment_matrix` |
| KPI / цели / OKR | `goals_rows` |
| Brand / EVP структура | `brand_pyramid` |
| Описание механизма / инструмента | `mechanism_card` |
| Процесс + TO BE инициативы | `process_detail` |
| Титул / next steps | `title_dark`, `next_steps` (⛔ divider ЗАПРЕЩЁН) |
| Executive summary | `exec_summary` |
| Декомпозиция изменений (было → стало) | `waterfall`, `from_to` |
| Приоритизация, позиционирование | `matrix` |
| Конверсия, воронка | `funnel`, `sankey` |
| SWOT / стратегический анализ | `swot` |
| Комбинация: числа + текст | `chart_table`, `multi_table` |

### Шаг 2: Подсчитай элементы → выбери макет

**Жёсткая привязка количества элементов к типу слайда:**

| Количество | Рекомендуемые типы | ❌ НЕ использовать |
|------------|-------------------|-------------------|
| 1 элемент | `data` (крупная метрика) | — |
| 2 элемента | `from_to`, `comparison` | — |
| 3 элемента | `scqa` (3 колонки), `comparison` | — |
| 4 элемента | `table`, `numbered_list`, `flow_blocks`, `comparison` | `scqa` (только 3 колонки!) |
| 5+ элементов | `table`, `numbered_list`, `flow_blocks`, `chevron_process` | `scqa`, `comparison` (макс 4!) |
| 7+ элементов | `table`, `numbered_list` (grid layout) | Любой макет с колонками |
| 10+ элементов | `table` с 10+ строками | Разбей на 2 слайда |

**КРИТИЧЕСКОЕ ПРАВИЛО: Если элементов больше, чем слотов в макете — ВЫБЕРИ ДРУГОЙ ТИП, а не обрезай контент!**

### Шаг 3: Проверь антимонотонность

Перед финальным выбором проверь, какие типы уже использованы в текущем слайдументе:
- Один тип — **не более 2 раз подряд**
- Если предыдущий слайд — `table`, текущий **НЕ ДОЛЖЕН** быть `table`
- Если последние 2 слайда — `scqa`, текущий **обязан** быть другим

→ Если нарушается — вернись к Шагу 1, найди альтернативу.

### Шаг 4: Эвристики содержания

| Паттерн в тексте | → Тип слайда |
|-----------------|-------------|
| "X% ... Y%" (процентные доли) | `chart` (pie/donut) или `treemap` |
| "рост с X до Y" / "до/после" | `from_to`, `waterfall`, `chart` (line) |
| "3 этапа / 5 шагов" | `chevron_process`, `flow_blocks` |
| "рекомендуем / необходимо / требуется" | `numbered_list`, `scqa` |
| "сильные/слабые стороны" | `swot` |
| "Q1, Q2, Q3, Q4" | `chart` (column/line) |
| "позиционирование / приоритизация" | `matrix` |
| "конверсия / воронка / потеря на этапе" | `funnel`, `sankey` |
| Таблица сравнения с числами в ячейках | `table` или `multi_table` |
| Декомпозиция P&L / мост изменений | `waterfall` |
| "почему / из-за чего / факторы" (декомпозиция) | `issue_tree` |
| Прямая цитата / интервью / "клиент сказал" | `quote` |
| "рекомендуем потому что... доказательства" | `pyramid` |

### Шаг 5: Таблица ошибок

| ❌ НЕПРАВИЛЬНЫЙ выбор | ✅ ПРАВИЛЬНЫЙ выбор | Почему |
|----------------------|---------------------|--------|
| 5 пунктов в `scqa` (3 колонки) | `numbered_list` или `table` | scqa = ровно 3 колонки, 5 не влезут |
| Декомпозиция P&L в `table` | `waterfall` | Мост нагляднее показывает вклад каждого фактора |
| Процесс из 4 этапов в `table` | `chevron_process` или `flow_blocks` | Процесс требует визуальных связей между этапами |
| До/после в `scqa` | `from_to` | Специализированный макет с визуальной трансформацией |
| 6 KPI в `scqa` | `multi_table` или `chart_table` | Много метрик → табличный или комбинированный формат |
| Все 15 слайдов — `table` | Микс из 6+ типов | Визуальное разнообразие = профессионализм |

### Шаг 6: Финальный чеклист

Перед генерацией JSON ответь:
1. ✅ Тип слайда соответствует характеру данных? (Шаг 1)
2. ✅ Количество элементов помещается в макет? (Шаг 2)
3. ✅ Нет монотонности — тип отличается от 2 предыдущих? (Шаг 3)
4. ✅ Эвристики содержания не указывают на другой тип? (Шаг 4)
5. ✅ Нет ошибки из таблицы Шаг 5?

# Промпты для Claude in PowerPoint Add-in

Руководство по использованию знаний из consulting-slides-creator в Claude in PowerPoint add-in.

> **Контекст:** Claude in PowerPoint — официальный add-in Anthropic, работающий внутри PowerPoint.
> Он читает slide master, шрифты и цвета текущей деки, но не знает консалтинговых стандартов.
> Эти промпты передают ему наши правила.

---

## 1. Базовые правила (вставить в начало любого промпта)

```
Правила генерации слайдов:
- Action Titles: каждый заголовок слайда = вывод/инсайт, НЕ тема.
  Плохо: "Обзор рынка". Хорошо: "Рынок растёт на 23% YoY за счёт e-commerce"
- Визуальное разнообразие: не более 2 одинаковых layout'ов подряд,
  максимум 30% таблиц в деке
- Числа → графики: если есть числовые данные, используй графики, а не таблицы
- Плотность: 60-80 слов на слайд, минимум 8 слов на буллет
- Язык: весь текст строго на русском, кроме устоявшихся терминов (KPI, ROI, EBITDA)
```

---

## 2. Промпты по задачам

### 2.1 Генерация деки с нуля

```
Создай 12 слайдов по теме: [ТЕМА].

Следуй этим правилам:
1. Action Titles в каждом заголовке — вывод, не тема
2. Распределение layout'ов:
   - 2-3 графика (bar, line, pie)
   - 2-3 буллет-листа с иконками
   - 1 таблица (максимум)
   - 1-2 process flow / timeline
   - 1 Executive Summary (первый или последний слайд)
3. Не более 2 одинаковых layout'ов подряд
4. Каждый слайд — самодостаточный: понятен без спикера
5. Числа из текста → визуализации, не просто текст
```

### 2.2 Превращение буллетов в консалтинговый формат

```
Перестрой этот слайд в консалтинговом формате:
1. Заголовок замени на Action Title (вывод/инсайт)
2. Если есть числа — вынеси в график или KPI-карточки
3. Если 3-5 этапов — сделай process flow (шевроны/стрелки)
4. Если сравнение — используй колонки или таблицу с highlight
5. Добавь внизу takeaway-бокс: одно предложение с ключевым выводом
```

### 2.3 Конвертация текста в графики

```
Найди в этой деке все слайды, где числовые данные представлены текстом.
Для каждого такого слайда:
- Процентные доли → pie chart или donut
- Динамика по периодам → line chart или bar chart
- Сравнение категорий → horizontal bar chart
- Рост/падение с промежуточными этапами → waterfall (если поддерживается)
Сохрани Action Title и добавь источник данных мелким текстом внизу.
```

### 2.4 Проверка качества деки (QA)

```
Проверь всю деку по чеклисту:

1. [ ] Action Titles: каждый заголовок — вывод, не тема?
2. [ ] Нет 3+ одинаковых layout'ов подряд?
3. [ ] Таблиц не более 30% от всех слайдов?
4. [ ] Буллеты ≥ 8 слов каждый?
5. [ ] Числа визуализированы (графики, KPI), а не текст?
6. [ ] Нет обрезанного/урезанного текста?
7. [ ] Единообразие: шрифты, размеры, выравнивание?
8. [ ] Takeaway / key message на ключевых слайдах?
9. [ ] Source/footnotes где нужны?
10. [ ] Executive summary отражает основные выводы деки?

Выведи таблицу: Слайд | Проблема | Рекомендация
```

### 2.5 Адаптация нашего PPTX под корп. шаблон

```
Прочитай все слайды в этой деке.
Контент генерировался в стиле Paper Planes (coral #FF5850, чёрный, серый).
Адаптируй под текущий slide master:
1. Замени цвета на палитру из slide master
2. Шрифты → корпоративные из шаблона
3. Сохрани всю структуру и данные
4. Логотип и footer — из slide master
5. НЕ меняй Action Titles и контент буллетов
```

### 2.6 Добавление speaker notes

```
Добавь speaker notes к каждому слайду:
- 3-4 предложения на слайд
- Начни с перехода от предыдущего слайда ("Как мы видели...", "Переходя к...")
- Раскрой данные и контекст, которые не влезли на слайд
- Закончи связкой к следующему слайду
- Тон: уверенный, деловой, без воды
```

### 2.7 SCQA-структура

```
Перестрой деку по структуре SCQA:
- Слайд 1: Situation — текущее положение дел, факты, контекст
- Слайд 2: Complication — что изменилось, в чём проблема/вызов
- Слайд 3: Question — ключевой вопрос, который мы решаем
- Слайды 4-N: Answer — решение, разбитое на логические блоки
- Финальный слайд: Next Steps с конкретными действиями, ответственными, сроками

Каждый слайд — Action Title. Между блоками — divider-слайды с номером секции.
```

### 2.8 Executive Summary

```
Прочитай всю деку и создай Executive Summary слайд:
- Заголовок: ключевой вывод всей презентации (Action Title)
- 3-5 блоков: по одному на каждую секцию деки
- Каждый блок: иконка + заголовок (2-3 слова) + описание (1 предложение)
- Внизу: рекомендация к действию (1 предложение, bold)
Поставь этот слайд вторым (после титульного).
```

## 5. Чего НЕ может add-in (делай в Claude Code)

- Waterfall / Sankey / Treemap / Issue Tree диаграммы
- RASCI-матрицы с Harvey Balls
- Roadmap swimlane с горизонтами
- Stage-gate процессы
- Brand Pyramid (RDB)
- Mermaid-диаграммы
- Точное позиционирование shape'ов (Emu-уровень)
- Trend-индикаторы в ячейках таблиц (↑↓→)
- Кастомные highlight'ы в таблицах

## Консалтинговые элементы

### Harvey Balls (визуализация степени)
```
○ = 0%    ◔ = 25%    ◑ = 50%    ◕ = 75%    ● = 100%
```
В таблицах: `"HB:75"` → ◕

### RAG Status (светофор)
```
● Зелёный (green) — реализовано, хорошо
● Жёлтый (yellow/amber) — в процессе, осторожно
● Красный (red) — отсутствует, плохо
```
В таблицах: `"RAG:green"` → цветной индикатор

### Нумерация в кружках
```
① ② ③ ④ ⑤ ⑥ ⑦ ⑧ ⑨ ⑩
```

## Ключевые принципы

### 1. Слайдументы — плотные документы
Читаются без спикера. Много информации, развёрнутые формулировки с цифрами и контекстом.

### 2. SCQA — принцип структурирования, НЕ подписи
- **Левая колонка**: ситуация (S)
- **Центральная**: осложнения (C)
- **Правая**: выводы и действия (A)

**НЕ ПИСАТЬ** слова "Situation", "Complication", "Answer"!

### 3. Action Titles везде
- Заголовок слайда = главный вывод
- Подзаголовки колонок = тоже action titles

❌ "Анализ продаж" → ✅ "Продажи упали на 15% из-за задержек доставки"

### 4. Триангуляция
Минимум 2 источника из разных категорий.

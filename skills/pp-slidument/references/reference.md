# Reference: Consulting Slides Creator

Подробная справка с примерами и шаблонами для создания консалтинговых слайдов.

## Примеры Action Titles

### Тематические (неправильно)
```
Итоги интервью
Динамика объема продаж
Анализ рынка
Обзор конкурентов
Результаты исследования
```

### Аналитические / Action Titles (правильно)
```
Необходимо запустить три пилота до конца квартала
Объем продаж вырос на 15% за счет трех категорий
Компания должна выйти на новый сегмент B2B для роста выручки
Три конкурента уже используют данную технологию
Исследование выявило 5 ключевых барьеров для клиентов
```

## Шаблон промпта для Manus

```
Создай консалтинговый слайд по следующим правилам:

=== СТРУКТУРА ===
Три колонки слева направо по принципу SCQA:
- Левая: ситуация и предпосылки (Situation)
- Центральная: осложнения и дополнительные факты (Complication)
- Правая: выводы и рекомендуемые действия (Answer)

=== ФОРМАТИРОВАНИЕ ===
- Шрифт: Inter
- Заголовок слайда: 16+ пт, жирный
- Подзаголовки блоков: 11-12 пт, жирный
- Основной текст: 9-11 пт
- Текст в таблицах: 7-8 пт
- Line spacing: 1.0
- Paragraph spacing: 0
- Выравнивание: по левому краю

=== ЦВЕТОВАЯ СХЕМА ===
- Коралловый (#FF5850): акценты, ключевые цифры, графики
- Серые уровни (#414651, #717680, #D5D7DA): иерархия данных
- Черный (sharp black): основной текст
- Белый (clean white): фон слайда

=== КОНТЕНТ ДЛЯ СЛАЙДА ===
[Вставить готовый контент с источниками]

=== ЗАГОЛОВОК (Action Title) ===
[Формулировка в виде вывода или рекомендации]

=== ИСТОЧНИКИ ===
[Минимум 2 источника из разных видов майнинга]
```

## Виды майнинга для триангуляции

Для триангуляции необходимо минимум 2 источника из разных категорий:

### Первичные источники
- Глубинные интервью
- Экспертные интервью
- Опросы клиентов
- Фокус-группы
- Наблюдения

### Вторичные источники
- Данные клиента (CRM, продажи, финансы)
- Бенчмаркинг конкурентов
- Отраслевые отчёты
- Аналитика рынка
- Публичные источники

## Примеры комбинаций для триангуляции

```
Интервью (15 респондентов) + Данные CRM клиента
Бенчмаркинг 5 конкурентов + Опрос 200 клиентов
Данные продаж за 3 года + Глубинные интервью с менеджерами
Отраслевой отчёт McKinsey + Собственный анализ данных клиента
```

## Типы слайдов и их применение

### 1. Слайд с данными
**Когда использовать:** Представление цифр, трендов, сравнений
**Элементы:**
- Графики (линейные, столбчатые, круговые)
- Таблицы с данными
- Ключевые метрики крупно
- Источники обязательны

### 2. Концептуальный слайд
**Когда использовать:** Объяснение идей, моделей, процессов
**Элементы:**
- Схемы и диаграммы
- Визуальные метафоры
- Минимум текста
- Геометрические фигуры

### 3. Слайд сравнения
**Когда использовать:** Выбор между вариантами, before/after
**Элементы:**
- Две или три колонки
- Критерии сравнения
- Визуальная дифференциация
- Рекомендация выделена

### 4. Генерализирующий слайд
**Когда использовать:** Перед группой детальных слайдов
**Элементы:**
- Общий вывод по группе
- Навигация (breadcrumbs)
- Геометрическая концепция
- Ссылки на детальные слайды

## Harvey Balls

Для визуализации степени соответствия или уровня:

```
◯ Пустой     = 0%  / Отсутствует
◔ Четверть   = 25% / Низкий
◑ Половина   = 50% / Средний
◕ Три четв.  = 75% / Высокий
● Полный     = 100% / Полный
```

## Примеры использования кружков в нумерации

```
Вместо:                      Использовать:
1) Первый пункт              ① Первый пункт
2) Второй пункт              ② Второй пункт
3) Третий пункт              ③ Третий пункт
```

## Визуальные связи

Для причинно-следственных связей:
```
▷ Треугольная стрелка (направление)
› Шеврон (последовательность)
→ Обычная стрелка (связь)
↗ Диагональная стрелка (рост)
```

## Чек-лист качества слайда

### Структура
- [ ] Заголовок — action title (говорит что делать)
- [ ] Три колонки: S → C → A
- [ ] Информация читается слева направо
- [ ] Выводы справа, предпосылки слева

### Содержание
- [ ] Минимум 2 источника информации
- [ ] Нет "воды" и общих фраз
- [ ] Конкретные цифры и факты
- [ ] Источники указаны

### Оформление
- [ ] Шрифт Inter
- [ ] Размеры шрифтов соответствуют стандартам
- [ ] Текст не выходит за направляющие
- [ ] Текст внутри фигур
- [ ] Таблицы через Insert > Table
- [ ] Корпоративные цвета

### Логика
- [ ] Заголовок следует из содержания
- [ ] Аргументы поддерживают вывод
- [ ] Нет логических разрывов
- [ ] MECE соблюдён

## Типичные ошибки и исправления

| Ошибка | Исправление |
|--------|-------------|
| Заголовок "Анализ продаж" | "Продажи выросли на 15% благодаря новому каналу" |
| Выводы внизу слайда | Переместить выводы в правую колонку |
| Один источник данных | Добавить второй источник (триангуляция) |
| Шрифт Arial | Заменить на Inter |
| Текст поверх фигуры | Поместить текст внутрь фигуры |
| Таблица из линий | Пересоздать через Insert > Table |
| Текст за границами | Включить направляющие, уменьшить |

## Workflow создания слайда

```
1. АНАЛИЗ
   └─ Определить главный вывод
   └─ Собрать поддерживающие факты
   └─ Проверить источники (мин. 2)

2. СТРУКТУРА
   └─ Сформулировать action title
   └─ Разбить на S-C-A колонки
   └─ Определить иерархию информации

3. ВЕРСТКА
   └─ Выбрать тип слайда
   └─ Применить шаблон
   └─ Расставить элементы

4. ПРОВЕРКА
   └─ Пройти чек-лист
   └─ Тест заголовка
   └─ Финальная вычитка
```

## AI Generation Master Prompt

Полный промпт для генерации слайдов через AI-инструменты:

```
=== REQUIREMENT ===
A professional, high-density consulting presentation slide, designed in the style of a top-tier strategy firm (McKinsey/BCG) blended with high-end editorial aesthetics.

=== CORE CONTENT & LAYOUT ===
1. Rich Data Visualization: The slide is populated with complex, precise charts (stacked bar charts, waterfall charts, or line graphs) and detailed data tables with rows and columns.
2. Structured Frameworks: Includes strategic diagrams or 2x2 (or bigger) matrices constructed with thin, clean lines.
3. High Information Density: The layout is sophisticated and multi-column, mimicking an actual business analysis deck, not just an empty cover page.

=== VISUAL STYLE ===
1. Aesthetic: Tech-minimalist but information-heavy. Clean, sharp, and authoritative.
2. Typography: Sans-Serif for the main headlines to give a premium financial report feel; clean Sans-Serif for chart labels and data numbers. Line spacing = 1.0
3. Color Palette: Clean white background. Text is sharp black. Charts and graphical accents use Coral #FF5850 and distinct shades of grey for data hierarchy.
4. Graphics: Use fine hairline borders for tables and precise vector lines for graphs.

=== STRUCTURE (SCQA) ===
- Left column: Situation and prerequisites
- Center column: Complications and additional facts
- Right column: Conclusions and recommended actions

=== ACTION TITLE ===
[Заголовок должен быть выводом или рекомендацией, не описанием темы]

=== CONTENT ===
[Готовый контент — AI НЕ должен придумывать факты]

=== SOURCES ===
[Минимум 2 источника из разных видов исследований]
```

## Типы визуализации данных

### Stacked Bar Charts (Составные столбчатые)
Когда использовать:
- Сравнение долей в целом
- Показ структуры по категориям
- Динамика изменения пропорций

### Waterfall Charts (Каскадные)
Когда использовать:
- Показ влияния факторов на итог
- Bridge-анализ (от A к B)
- Декомпозиция изменений

### Line Graphs (Линейные)
Когда использовать:
- Тренды во времени
- Сравнение динамики нескольких показателей
- Прогнозы

### 2x2 Matrices (Матрицы)
Когда использовать:
- Приоритизация
- Сегментация
- Стратегический выбор

## Стандарты графических элементов

### Линии и границы
- **Fine hairline borders** для таблиц (0.5-1 pt)
- **Precise vector lines** для графиков
- **Thin, clean lines** для фреймворков
- Избегать толстых линий и теней

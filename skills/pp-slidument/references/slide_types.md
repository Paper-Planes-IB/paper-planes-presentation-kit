# Библиотека типов слайдов Paper Planes

> Построена на основе анализа 1261 слайда из 20 реальных проектов (57 презентаций).
> Каждый тип включает: когда использовать, входные данные, паттерн верстки, структуру контента.

---

## Как использовать

1. Определи фазу проекта и доступные данные
2. Найди подходящий тип слайда по категории
3. Используй паттерн верстки и структуру контента как шаблон
4. Помни: каждый слайд = action title + SCQA + минимум 2 источника

### Decision Tree: Фаза → Тип слайда

| Фаза проекта | Доступные данные | Рекомендуемые типы |
|---|---|---|
| Аналитический этап | Интервью, опросы, desk research | A1-A4, B1-B4, C1-C5 |
| Стратегия | Выводы аналитики, бенчмарки | D1-D6, E1-E4 |
| Рекомендации | Расчёты, roadmap | E1-E5, D5-D6 |
| Брендинг | Позиционирование, ЦА, конкуренты | F1-F4 |
| Навигация | — | G1-G4 |

## A. Исследования и сбор данных

### A1. Сводка интервью
**Частота:** 100 из 1261 слайдов (8%)
**Применимость:** Universal
**Когда:** После проведения глубинных интервью (10+ респондентов)

**Входные данные:**
- Транскрипты/заметки интервью
- Количество и роли респондентов
- Ключевые темы и цитаты

**Паттерн верстки:**
- Заголовок: action title с главным выводом
- 3 колонки SCQA или блочная структура 3-5 тем
- Каждый блок: тема (bold) + 2-3 факта/цитаты
- Подвал: источник "Глубинные интервью, N=15, [период]"

**Структура контента:**
- Квантифицировать: "12 из 15 респондентов отметили..."
- Прямые цитаты в кавычках курсивом
- Группировка по темам, не по респондентам

**Примеры:** Acoustic АТС (слайды 15-25), КВАНТ (слайды 8-18)

---

### A2. Результаты опроса
**Частота:** 150 из 1261 слайдов (12%) — самый частый тип данных
**Применимость:** Universal (чаще B2C)
**Когда:** Количественные данные из опросов (50+ респондентов)

**Входные данные:**
- Результаты анкетирования
- Выборка, методология
- Статистические разбивки

**Паттерн верстки:**
- Заголовок: action title с ключевым числом
- Центр: графики (столбчатые, круговые) или таблица с %
- Боковая панель: методология (N=, период, метод)
- Подвал: источник "Онлайн-опрос, N=500, [период]"

**Структура контента:**
- Каждый вопрос = отдельный слайд или блок
- Визуализация: bar chart для сравнений, pie для долей
- Выделять аномалии и главные паттерны в action title

**Примеры:** УМЕТ_опросы (весь файл), Венеция АТС (слайды 30-45)

### A3. Тайный покупатель
**Частота:** 6 из 1261 (редкий, но важный)
**Применимость:** B2C

**Входные данные:**
- Чек-листы оценки

**Паттерн верстки:**

- Фотографии или скриншоты (если есть)
- Рекомендации по каждому критерию

**Структура контента:**
- Скоринговая таблица с цветовой кодировкой (зелёный/жёлтый/красный)
- Сравнение точек между собой
- Конкретные нарушения с фото

**Примеры:** ХлебХмельницкого (слайды 20-28)

### A4. NPS / Индекс лояльности

**Применимость:** Universal (чаще B2C)
**Когда:** Есть данные по лояльности клиентов

**Входные данные:**
- Результаты NPS-опроса
- Сегментация: промоутеры/нейтралы/критики

- Центр: шкала NPS с долями промоутеров/критиков

## B. Рынок и конкуренты

### B1. Анализ конкурентов / Конкурентная матрица
**Частота:** 183 из 1261 (15%) — второй по частоте
**Применимость:** Universal
**Когда:** Desk research по конкурентам завершён

**Входные данные:**
- Список конкурентов (5-10)
- Критерии сравнения (7-15)
- Данные по каждому критерию

**Паттерн верстки:**
- Заголовок: action title с главным конкурентным выводом
- Таблица: конкуренты × критерии
- Цветовая кодировка ячеек (Harvey balls или ✓/✗/◐)
- Левая колонка: критерии, верхняя строка: конкуренты

**Структура контента:**
- Критерии MECE: цена, ассортимент, география, маркетинг, сервис...
- Источники под таблицей: сайты, отчёты, интервью
- Выделить конкурентные преимущества и разрывы

**python-pptx:**
- Таблица с merged cells для заголовков
- Цветовая заливка ячеек через `cell.fill`
- Минимум 10pt шрифт в ячейках таблицы

**Примеры:** BI.Zone (слайды 30-50), Acoustic АТС (слайды 40-55), Рыбинсккомплекс (слайды 35-50)

---

### B2. Размер рынка / Market Sizing (TAM/SAM/SOM)
**Частота:** 32 из 1261 (3%)
**Применимость:** Universal
**Когда:** Оценка объёма целевого рынка

**Входные данные:**
- Данные по PAM/TAM/SAM/SOM
- Bottom-up и top-down расчёты
- Источники (класс A-Д по шкале респектабельности)

**Паттерн верстки:**
- Заголовок: action title с цифрой объёма рынка
- Центр: вложенные круги или воронка TAM→SAM→SOM
- Правая колонка: допущения и источники
- Подвал: методология расчёта

**Структура контента:**
- Цифры в млрд/млн руб.
- Двойной расчёт (top-down + bottom-up) для валидации
- CAGR за 3-5 лет

**Примеры:** МЖ АТС (слайды 10-14), Рыбинсккомплекс (слайды 15-20)

**Входные данные:**
- Отраслевые отчёты и прогнозы

**Паттерн верстки:**
- Заголовок: action title с ключевым трендом
- 3-5 блоков трендов (иконка + описание)
- Или: линейный график динамики + комментарии

**Примеры:** Ringo стратегия (слайды 5-8), АГНИ (слайды 10-15)

---

### B4. Porter / Барьеры входа
**Частота:** 4 из 1261
**Применимость:** B2B
**Когда:** Анализ привлекательности отрасли

**Входные данные:**
- Оценка 5 сил Портера
- Барьеры входа/выхода

**Паттерн верстки:**
- Центр: диаграмма 5 сил (пентагон или звезда)
- Вокруг: описание каждой силы с оценкой (высокая/средняя/низкая)
- Итоговый вывод о привлекательности

## C. Клиент и путь клиента

### C1. Сегментация / Портрет клиента
**Частота:** 199 из 1261 (16%) — САМЫЙ частый тип
**Применимость:** Universal
**Когда:** Есть данные о клиентах (интервью, опросы, CRM)

**Входные данные:**
- Демография, поведение, потребности клиентов
- Критерии сегментации
- Размер каждого сегмента

**Паттерн верстки:**
- Заголовок: action title о ключевом сегменте
- 3-5 карточек сегментов (каждая: название, портрет, ключевые характеристики, потребности, объём)
- Или: таблица сегмент × характеристики
- Подвал: источник данных

**Структура контента:**
- Каждый сегмент: имя (архетип), 3-5 характеристик, ключевая потребность, объём/доля
- Сегменты MECE (взаимоисключающие, коллективно исчерпывающие)
- Приоритетный сегмент выделен визуально

**python-pptx:**
- Карточки: прямоугольники с заливкой + текст внутри
- Или: многоколоночная таблица
- Иконки/пиктограммы для каждого сегмента (опционально)

**Примеры:** ОХАНА (слайды 15-30), Kulikov АТС (слайды 20-35), Копия_075 (слайды 25-40)

---

### C2. CJM / Customer Journey Map
**Частота:** 54 из 1261 (4%)
**Применимость:** B2C (реже Universal)
**Когда:** Исследование пути клиента завершено

**Входные данные:**
- Этапы пути клиента
- Точки контакта на каждом этапе
- Боли и потребности на каждом этапе
- Источники: интервью, наблюдения, тайный покупатель

**Паттерн верстки:**
- Заголовок: action title о главной проблеме пути
- Горизонтальная timeline: этапы слева направо
- Строки: этап → действия → точки контакта → боли → возможности
- Цветовая кодировка: красный (боли), зелёный (возможности)

**Структура контента:**
- 5-8 этапов (Осознание → Поиск → Выбор → Покупка → Использование → Рекомендация)
- Каждый этап: 2-3 ключевых touchpoint
- Эмоциональная кривая (опционально)

**Примеры:** Финестра CJM Архитекторы (весь файл), ХлебХмельницкого (слайды 30-40)

---

### C3. Воронка / Конверсия
**Частота:** 32 из 1261 (3%)

**Входные данные:**
- Количество/% на каждом этапе воронки

**Паттерн верстки:**
- Заголовок: action title о главном узком месте
- Воронка (трапеции сужающиеся вниз) с % на каждом этапе
- Стрелки потерь между этапами
- Правая колонка: рекомендации по улучшению

- CAC, LTV, ARPU, churn rate

**Паттерн верстки:**

### C5. Финансовые показатели

**Применимость:** Universal

- Финансовая отчётность

**Паттерн верстки:**

## F. Брендинг

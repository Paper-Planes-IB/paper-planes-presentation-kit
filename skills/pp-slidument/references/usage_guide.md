# Гайд: как давать вводные для создания слайдументов

> Этот документ — инструкция для пользователя (и для Claude), как правильно формулировать запрос на создание презентации, чтобы результат был максимально качественным с первого раза.

---

## Общий принцип

**Слайдумент = данные + структура + выводы.**

Claude не придумывает факты. Чем больше конкретных данных во вводных — тем плотнее и полезнее слайд. Пустой запрос → пустой слайд.

---

## Минимальный набор для любого запроса

Каждый запрос на создание презентации должен содержать:

| Что | Зачем | Пример |
|-----|-------|--------|
| **Клиент** | Палитра, логотип, отрасль | «Берёзка», сеть пекарен, B2C |
| **Тип проекта** | Определяет набор слайдов | АТС, маркетинговая стратегия, аналитический этап |
| **Фаза** | Какие типы слайдов уместны | Аналитика → A, B, C; Стратегия → D, E |
| **Количество слайдов** | Масштаб и уровень детализации | 25–30 слайдов |
| **Данные** | Факты, цифры, таблицы | См. ниже по типам |

---

## Как подавать данные для каждого типа слайда

### A. Исследования

#### A1. Сводка интервью
```
Что дать:
- Количество респондентов и их роли (CEO, CMO, менеджеры, клиенты)
- По каждой теме: факт + сколько респондентов подтвердили
- Прямые цитаты (2-3 лучших)
- Период проведения

Пример вводной:
"Проведено 15 глубинных интервью (5 топ, 5 мидл, 5 клиентов), март 2026.
Тема 1: Отток клиентов — 12 из 15 указали на долгие сроки доставки.
Цитата: «Мы ждём 14 дней, у конкурента — 5» (CEO, Компания Х).
Тема 2: ..."
```

#### A2. Результаты опроса
```
Что дать:
- Выборка (N=), метод (онлайн, телефон), период
- Таблица: вопрос → варианты ответов → % по каждому
- Или: Excel/CSV с сырыми данными

Пример вводной:
"Онлайн-опрос, N=500, апрель 2026.
Q1: Как часто покупаете? Ежедневно 12%, 2-3 раза в неделю 34%, раз в неделю 28%, реже 26%.
Q2: Что влияет на выбор? Цена 67%, ассортимент 45%, расположение 38%..."
```

#### A3. Тайный покупатель
```
Что дать:
- Количество визитов, точки
- Чек-лист критериев с баллами (1-5 или 1-10)
- Конкретные нарушения

Пример:
"7 визитов в 4 точки + 3 конкурента.
Критерии: чистота (наш 3.2, конкурент А 4.5), скорость обслуживания (наш 2.8, конкурент А 4.0)..."
```

#### A4. NPS / Лояльность
```
Что дать:
- NPS-индекс (число от -100 до +100)
- Доли: промоутеры %, нейтралы %, критики %
- Бенчмарк по отрасли (если есть)
- Причины оценок (топ-3 у промоутеров и критиков)
```

---

### B. Рынок и конкуренты

#### B1. Анализ конкурентов
```
Что дать:
- Список конкурентов (5-10 шт.) с названиями
- Критерии сравнения (7-15 шт.)
- Данные по каждой ячейке (✓/✗, баллы, или текст)
- Источники данных

Пример:
"Конкуренты: Альфа, Бета, Гамма, Дельта.
Критерии: выручка, кол-во точек, ассортимент, цены, доставка, лояльность, digital.
Альфа: 2.5 млрд, 120 точек, 500 SKU, средний+, да, нет, сильный.
Бета: 1.8 млрд, 80 точек, 300 SKU, средний, нет, да, слабый.
..."
```

**Лучший формат:** таблица в Excel или Google Sheets. Можно просто скопировать.

#### B2. Market Sizing (TAM/SAM/SOM)
```
Что дать:
- Цифры PAM/TAM/SAM/SOM (или хотя бы TAM и SOM)
- Источники и методы расчёта (top-down, bottom-up)
- CAGR
- Допущения

Пример:
"TAM рынка кофеен РФ: 450 млрд руб. (Euromonitor 2025).
SAM (Москва, specialty): 28 млрд.
SOM (наша доля через 3 года): 1.2 млрд.
CAGR 2023-2028: 8%."
```

#### B3. Тренды рынка
```
Что дать:
- 3-5 ключевых трендов с цифрами
- Источники (отраслевые отчёты, статистика)
```

#### B4. Porter / Барьеры
```
Что дать:
- Оценка каждой из 5 сил (высокая/средняя/низкая) + обоснование
```

---

### C. Клиент и путь

#### C1. Сегментация / Портрет
```
Что дать:
- Количество сегментов (3-5)
- По каждому: название-архетип, демография, поведение, потребности, объём/доля
- Критерии сегментации (по чему делили)

Пример:
"Сегмент 1: «Экономный практик» — 40% клиентов. М/Ж 25-45, доход средний, покупает базовый ассортимент, чувствителен к цене, средний чек 350 руб.
Сегмент 2: «Гурман» — 15% клиентов. Ж 30-50, доход выше среднего, выбирает премиум, ценит качество, средний чек 890 руб..."
```

#### C2. CJM
```
Что дать:
- Этапы пути (5-8 шт.)
- По каждому этапу: действия клиента, точки контакта, боли, возможности
- Источник (интервью, наблюдения)

Пример:
"Этап 1: Осознание потребности. Действия: видит рекламу, слышит от знакомых. Точки контакта: Instagram, сарафан. Боль: не знает о нас. Возможность: таргет по look-alike.
Этап 2: Поиск..."
```

#### C3. Воронка
```
Что дать:
- Этапы воронки с абсолютными числами или %
- Конверсия между этапами
- Бенчмарк (если есть)
```

#### C4. Unit-экономика
```
Что дать:
- CAC, LTV, ARPU, средний чек, частота покупок, churn rate
- Формулы расчёта (по желанию)
```

#### C5. Финансовые показатели
```
Что дать:
- Выручка, EBITDA, чистая прибыль за 3-5 лет
- Структура выручки по каналам/продуктам
- Маржинальность
```

---

### D. Стратегические фреймворки

#### D1. Позиционирование
```
Что дать:
- Формулировка позиционирования: [Бренд] — для [ЦА] — это [категория] — который [отличие] — потому что [RTB]
- Конкурентная карта (оси + позиции игроков)
```

#### D2. Декомпозиция
```
Что дать:
- Структура целого (выручка, время, процесс)
- Доли каждого элемента
- Что растёт, что падает
```

#### D3. Ассортиментная матрица
```
Что дать:
- Список SKU/категорий
- По каждому: выручка, маржа, роль (трафикогенератор/маржмейкер/имиджевый)
- Рекомендация (развивать/оптимизировать/вывести)
```

#### D4. Скоринг / Приоритизация
```
Что дать:
- Список альтернатив
- Критерии оценки с весами
- Баллы по каждой ячейке
```

#### D5. Бизнес-процессы
```
Что дать:
- Описание процесса as-is (этапы, ответственные, SLA)
- Проблемные точки
- Целевой процесс to-be (если есть)
```

#### D6. Оргструктура
```
Что дать:
- Текущая структура (подразделения, подчинённость)
- FTE, ФОТ (если есть)
- Функциональные пробелы
```

---

### E. Рекомендации и синтез

#### E1. Рекомендации / План действий
```
Что дать:
- Список рекомендаций (3-7) с приоритетами
- По каждой: что сделать, ожидаемый эффект, срок, ответственный
```

#### E2. Executive Summary
```
Что дать:
- 5-7 главных выводов из всей аналитики
- Каждый с цифрой и источником
```

#### E3. Roadmap
```
Что дать:
- Этапы реализации (Q1-Q4 или помесячно)
- Задачи по направлениям (маркетинг, продукт, HR)
- Ключевые милестоуны с датами
```

#### E4. ROI
```
Что дать:
- Инвестиции (разовые + ежемесячные)
- Ожидаемый эффект (доп. выручка или экономия)
- Срок окупаемости
- 3 сценария (если есть)
```

---

### F. Брендинг

#### F1-F4. Бренд-платформа, айдентика, коммуникации, контент
```
Что дать:
- Бренд: миссия, ценности, характер, essence, promise
- Айдентика: логотип (файл), цвета (HEX), шрифты
- Коммуникации: ЦА × сообщение × канал
- Контент: рубрикатор, примеры, частота
```

---

## Форматы подачи данных (от лучшего к худшему)

| Формат | Качество | Комментарий |
|--------|----------|-------------|
| **Excel/CSV таблица** | Отлично | Структурированные данные → точные слайды |
| **Текст с цифрами** | Хорошо | «12 из 15 респондентов...», «выручка 2.5 млрд» |
| **Скопированный текст из отчёта** | Нормально | Claude извлечёт факты, но может потерять структуру |
| **Общее описание** | Слабо | «Сделай слайд про конкурентов» → будет пустой |
| **Ничего** | Не работает | Без данных = без слайда |

---

## Структура запроса (шаблон)

```
Сделай презентацию [тип]:
- Клиент: [название, отрасль]
- Тип проекта: [АТС / маркетинговая стратегия / аналитический этап / ...]
- Количество слайдов: [N]
- Содержание:
  1. [Раздел]: [данные]
  2. [Раздел]: [данные]
  ...

Данные:
[таблицы, цифры, цитаты, файлы]
```

## Примеры хороших и плохих запросов

### Плохо
> «Сделай презентацию аналитического этапа для Берёзки на 30 слайдов»

Результат: шаблон с заглушками, без данных, action titles невозможны.

### Средне
> «Сделай АТС для Берёзки (сеть пекарен, B2C, 45 точек Москва). 25 слайдов. Включи: конкурентный анализ, сегментацию, CJM, рекомендации.»

Результат: структура правильная, но данных нет → слайды будут с примерными формулировками.

### Хорошо
> «Сделай АТС для Берёзки (сеть пекарен, B2C, 45 точек Москва). 25 слайдов.
>
> Конкуренты (таблица прикреплена): Буше, Волконский, Пекарня Мишеля, Братья Караваевы. Критерии: кол-во точек, средний чек, ассортимент, доставка, лояльность.
>
> Сегменты: Экономный (40%, чек 280), Гурман (15%, чек 890), Мамы (25%, чек 520), Офисный (20%, чек 350).
>
> NPS = +32. Промоутеры 48%, критики 16%. Главная жалоба — очереди.
>
> Интервью: 12 глубинных (4 топ, 4 линейных, 4 клиента). Ключевое: 10 из 12 — «ассортимент не обновляется».
>
> Рекомендации: 1) Обновление меню каждые 2 месяца (эффект +8% к среднему чеку). 2) Интеграция с Яндекс.Еда (эффект +12% к выручке). 3) Программа лояльности (удержание +15%).»

Результат: полноценная презентация с action titles, конкретными цифрами, триангуляцией.

---

## Правила, которые Claude соблюдает автоматически

Тебе **не нужно** просить об этом — скилл сделает сам:

1. **Action titles** — заголовок = вывод, не тема
2. **SCQA** — структура слева направо на каждом слайде
3. **Триангуляция** — минимум 2 источника
4. **MECE** — без пересечений и пропусков
5. **Палитра Paper Planes** — коралл, серый, белый
6. **Шрифт 10pt+** — никогда мельче
7. **Нет теней** — чистый минималистичный стиль
8. **normAutofit** — текст не выходит за границы
9. **Плотность 1000-1500 символов** на контентный слайд

## Чек-лист перед отправкой запроса

- [ ] Указал клиента и отрасль
- [ ] Указал тип проекта (АТС, стратегия, аналитика...)
- [ ] Указал количество слайдов
- [ ] Приложил данные с цифрами (не «в общем виде»)
- [ ] Конкуренты: есть названия + критерии + баллы/данные
- [ ] Сегменты: есть названия + характеристики + доли
- [ ] Цитаты из интервью: с указанием роли респондента
- [ ] Рекомендации: с ожидаемым эффектом

# Визуальный стиль презентаций Paper Planes

Версия палитры: 2026-07-12.

## Канонические переменные

```css
:root {
  --ink: #181D27;
  --steel: #414651;
  --muted: #717680;
  --line: #D5D7DA;

  --soft: #F7F8FA;
  --soft-2: #EEF1F5;
  --page: #F5F5F5;
  --white: #FFFFFF;

  --coral: #FF5850;
  --coral-soft: #FFEBEA;

  --green: #B8DAB3;
  --green-soft: #EEF7EC;
  --yellow-soft: #FFF5D8;
  --blue-soft: #E6EEF2;

  --mg-pink: #FFE9E7;
  --mg-navy: #181D27;
}
```

## Роли цветов

| Переменная | HEX | Назначение |
|---|---|---|
| `ink` | `#181D27` | Основной текст, тёмные плашки, сильные контуры |
| `steel` | `#414651` | Вторичный текст и подписи с повышенным контрастом |
| `muted` | `#717680` | Служебные подписи, номера, пояснения |
| `line` | `#D5D7DA` | Разделители, рамки, линии таблиц |
| `soft` | `#F7F8FA` | Первый уровень мягкого фона |
| `soft-2` | `#EEF1F5` | Второй уровень мягкого фона |
| `page` | `#F5F5F5` | Фон страницы вокруг слайдов |
| `white` | `#FFFFFF` | Основной фон слайда и карточек |
| `coral` | `#FF5850` | Главный акцент и сигнал внимания |
| `coral-soft` | `#FFEBEA` | Мягкий фон для кораллового акцента |
| `green` | `#B8DAB3` | Спокойный зелёный акцент |
| `green-soft` | `#EEF7EC` | Мягкий фон положительного или подтверждённого состояния |
| `yellow-soft` | `#FFF5D8` | Мягкий фон зоны внимания или ожидания |
| `blue-soft` | `#E6EEF2` | Мягкий фон информационного блока |
| `mg-pink` | `#FFE9E7` | Совместимость с ранним MG-слоем |
| `mg-navy` | `#181D27` | Совместимость с ранним MG-слоем; совпадает с `ink` |

## Правила использования

- Белый является основным фоном слайда.
- `ink` используется для основного текста. `steel` и `muted` задают вторичные уровни.
- `coral` отмечает один главный акцент на экране. Он не должен окрашивать каждый блок.
- Мягкие фоны помогают различать смысловые статусы. Их значение должно сохраняться по всей деке.
- `green-soft`, `yellow-soft` и `blue-soft` нельзя чередовать ради декоративного разнообразия.
- Рамки строятся на `line`; тяжёлые обводки и тени не используются.
- Старые переменные PAPER `#EFEBE7`, BLUE `#4A6FA5`, GREEN `#5A9A5E`, GOLD `#C79A3A` и PURPLE `#8B6DB5` не входят в текущую палитру.

## Типографика и размер

- Рабочий HTML-слайд: 1600 × 900 или 1280 × 720, строго 16:9.
- Основной шрифт: PT Sans, если проект не задаёт другую утверждённую пару.
- Заголовок сообщает управленческий вывод.
- Основной текст и служебные подписи должны оставаться читаемыми после экспорта в PPTX.
- Минимальный размер текста в PowerPoint — 10 pt.

## Глобальные элементы

Логотип, номер страницы, поля и служебные зоны задаются в общем шаблоне или генераторе. Их положение и размер одинаковы на всех слайдах, где они предусмотрены.
